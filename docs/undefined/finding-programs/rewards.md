# ប្រព័ន្ធរង្វាន់ និងកេរ្តិ៍ឈ្មោះ

នៅលើ DevSolve ការខិតខំប្រឹងប្រែងរបស់អ្នកក្នុងការស្វែងរក និងរាយការណ៍ចន្លោះប្រហោងសុវត្ថិភាព នឹងទទួលបានការតបស្នងទាំងផ្នែកហិរញ្ញវត្ថុ និងកេរ្តិ៍ឈ្មោះក្នុងសហគមន៍។

***

## 🏆 ពិន្ទុកេរ្តិ៍ឈ្មោះ (Reputation Points System)

ពិន្ទុ Reputation បង្ហាញពីកម្រិតជំនាញ ភាពជឿជាក់ និងគុណភាពនៃរបាយការណ៍របស់អ្នកនៅលើ Platform៖

| សកម្មភាព ឬស្ថានភាពនៃ Report           | ពិន្ទុទទួលបាន / កាត់ចេញ                |
| ------------------------------------- | -------------------------------------- |
| **Critical Report** ត្រូវបាន Resolved | **+50 Points**                         |
| **High Report** ត្រូវបាន Resolved     | **+30 Points**                         |
| **Medium Report** ត្រូវបាន Resolved   | **+15 Points**                         |
| **Low Report** ត្រូវបាន Resolved      | **+5 Points**                          |
| **Duplicate Report** (ដំបូង)          | **0 Points** (មិនកាត់ពិន្ទុ)           |
| **Informative Report**                | **+1 Point**                           |
| **Spam / Malicious / Fake Report**    | **-15 Points** (អាចឈានដល់ការផ្អាកគណនី) |

* **អត្ថប្រយោជន៍នៃ Reputation ខ្ពស់:** ទទួលបានការអញ្ជើញចូលរួមក្នុង **Private Bounty Programs**, ទទួលបានអត្រាប្រាក់រង្វាន់ខ្ពស់ជាងមុន និងឈរលើកំពូលតារាង Leaderboard។

***

## 💵 ការទូទាត់ប្រាក់រង្វាន់ (Bounties & Payouts)

នៅពេលដែលក្រុមហ៊ុនចុចអនុម័ត Bounty ទឹកប្រាក់នឹងត្រូវបញ្ចូលទៅក្នុង **DevSolve Balance / Wallet** របស់អ្នកភ្លាមៗ៖

1. **ការពិនិត្យសមតុល្យ:** ចូលទៅកាន់ទំព័រ [**Rewards & Balance**](../../../dashboard/rewards/) ដើម្បីមើលចំនួនទឹកប្រាក់ដែលទទួលបាន ប្រវត្តិប្រតិបត្តិការ និងស្ថានភាពដកប្រាក់។
2. **វិធីសាស្រ្តដកប្រាក់ (Payout Methods):**
   * **Bank Transfer (ផ្ទេរតាមធនាគារក្នុងស្រុក/អន្តរជាតិ)**
   * **PayPal / Payoneer / Stripe**
   * **Cryptocurrency (USDT / USDC)** (អាស្រ័យលើការកំណត់ក្នុងតំបន់)
3. **រយៈពេលដកប្រាក់:** ការស្នើសុំដកប្រាក់ជាធម្មតាត្រូវបានដំណើរការក្នុងរយៈពេល **២ ទៅ ៥ ថ្ងៃនៃថ្ងៃធ្វើការ** បន្ទាប់ពីការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ (KYC/Identity verification) ត្រូវបានអនុម័ត។
