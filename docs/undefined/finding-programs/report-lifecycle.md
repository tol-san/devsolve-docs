# របៀបតាមដាន Report Status

បន្ទាប់ពីអ្នកបានផ្ញើ Report រួច របាយការណ៍នឹងឆ្លងកាត់ដំណាក់កាលជាច្រើនរហូតដល់ត្រូវបានដោះស្រាយ និងបើកប្រាក់រង្វាន់។

***

## 🔄 វដ្តជីវិតនៃរបាយការណ៍ (Report States)

```
[New / Pending] ➔ [Triaged] ➔ [Resolved] ➔ [Bounty Awarded]
       │               │
       ├── [Duplicate] └── [Informative / Not Applicable]
       └── [Spam / Out of Scope]
```

### ១. `New / Pending` (រង់ចាំការពិនិត្យ)

* របាយការណ៍ត្រូវបានបញ្ជូនទៅកាន់ Inbox របស់ក្រុមហ៊ុន ឬ Triager រួចរាល់ហើយ។
* កំពុងរង់ចាំក្រុមការងារបើកមើល និងផ្ទៀងផ្ទាត់ជំហាន PoC។

### ២. `Triaged` (ទទួលស្គាល់ និងបញ្ជាក់ថាត្រឹមត្រូវ)

* ក្រុមហ៊ុនបានធ្វើតេស្តតាមជំហានរបស់អ្នក ហើយបញ្ជាក់ថាចន្លោះប្រហោងនេះពិតជាកើតឡើងមែន ស្ថិតក្នុង Scope និងមិនទាន់មានអ្នកណារាយការណ៍ពីមុនឡើយ។
* របាយការណ៍ត្រូវបានបញ្ជូនបន្តទៅកាន់ Developer Team របស់ក្រុមហ៊ុនដើម្បីសរសេរ Patch កែសម្រួល។

### ៣. `Resolved` (ដោះស្រាយរួចរាល់)

* ក្រុមហ៊ុនបានធ្វើការ Deploy កូដជួសជុលចន្លោះប្រហោងនោះនៅលើ Production រួចរាល់។
* ដំណាក់កាលនេះជារឿយៗត្រូវបានភ្ជាប់មកជាមួយការបើកប្រាក់រង្វាន់ (Bounty Payout) និងការបន្ថែមពិន្ទុ Reputation។

### ៤. `Duplicate` (ជាន់គ្នាជាមួយអ្នកដទៃ)

* ចន្លោះប្រហោងនេះត្រូវបានរកឃើញ និងរាយការណ៍ដោយ Researcher ម្នាក់ផ្សេងទៀតមុនអ្នករួចហើយ (First come, first served)។
* _ចំណាំ:_ Duplicate Report មិនទទួលបានប្រាក់រង្វាន់ទេ ប៉ុន្តែមិនប៉ះពាល់អវិជ្ជមានដល់ Reputation របស់អ្នកឡើយ។

### ៥. `Informative` (ជាព័ត៌មាន ប៉ុន្តែគ្មានហានិភ័យធ្ងន់ធ្ងរ)

* បញ្ហាដែលបានរាយការណ៍មានពិតមែន ប៉ុន្តែមិនបង្កើតជាហានិភ័យផ្នែកសុវត្ថិភាពច្បាស់លាស់ ឬជាចេតនានៃការរចនាប្រព័ន្ធរបស់ក្រុមហ៊ុន (Accepted Risk)។

### ៦. `Out of Scope / Not Applicable` (ខុសគោលការណ៍)

* របាយការណ៍ស្ថិតនៅលើ Asset ដែលក្រុមហ៊ុនបានហាមឃាត់ ឬគ្មានភស្តុតាងគ្រប់គ្រាន់។

***

## 💬 ការឆ្លើយឆ្លងតាមរយៈ Comment

* នៅខាងក្រោមទំព័រ Report នីមួយៗ មានប្រព័ន្ធ Comment សម្ងាត់រវាងអ្នក និងក្រុមការងារក្រុមហ៊ុន។
* ប្រសិនបើក្រុមហ៊ុនត្រូវការព័ត៌មានបន្ថែម (Need More Info) អ្នកនឹងទទួលបាន Notification។ សូមឆ្លើយតបឱ្យបានរហ័ស និងប្រកបដោយវិជ្ជាជីវៈ។
