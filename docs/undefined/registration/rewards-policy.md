# ការកំណត់រង្វាន់ Bounty

ការកំណត់កម្រិតរង្វាន់ដែលសមរម្យ និងមានតម្លាភាព នឹងលើកទឹកចិត្តឱ្យ Hackers កម្រិតកំពូលចំណាយពេលស្រាវជ្រាវលើប្រព័ន្ធរបស់អ្នក។

***

## 📊 តារាងកម្រិតប្រាក់រង្វាន់តាម Severity (Bounty Grid)

នៅលើ DevSolve កម្រិតទឹកប្រាក់ត្រូវបានកំណត់តាមស្តង់ដារ CVSS v3.1៖

| Severity     | ពិន្ទុ CVSS | ឧទាហរណ៍នៃចន្លោះប្រហោង                                                                          | កម្រិតទឹកប្រាក់រង្វាន់ដែលណែនាំ |
| ------------ | ----------- | ---------------------------------------------------------------------------------------------- | ------------------------------ |
| **Low**      | 0.1 - 3.9   | Open Redirects, Non-sensitive information disclosure, Missing security headers                 | $50 – $200                     |
| **Medium**   | 4.0 - 6.9   | Cross-Site Scripting (XSS), CSRF with moderate impact, Sensitive cookie without HttpOnly       | $200 – $800                    |
| **High**     | 7.0 - 8.9   | SQL Injection, Server-Side Request Forgery (SSRF), Broken Access Control, Privilege Escalation | $800 – $2,500                  |
| **Critical** | 9.0 - 10.0  | Remote Code Execution (RCE), Authentication Bypass, Complete Database Compromise               | $2,500 – $10,000+              |

***

## 💡 គោលការណ៍ណែនាំក្នុងការផ្តល់រង្វាន់

1. **First-Come, First-Served (អ្នកណា Submit មុនបានរង្វាន់):**
   * ប្រសិនបើមាន Researcher ២ នាក់រាយការណ៍ពីបញ្ហាដូចគ្នា (Duplicate) អ្នកដែលបាន Submit មុនគេតាម timestamp នឹងទទួលបានប្រាក់រង្វាន់ពេញលេញ។
2. **Discretionary Bonuses (ប្រាក់លើកទឹកចិត្តបន្ថែម):**
   * ក្រុមហ៊ុនអាចផ្តល់ប្រាក់បន្ថែមលើសពីតម្លៃកំណត់ក្នុងតារាង ប្រសិនបើរបាយការណ៍នោះមានគុណភាពល្អឥតខ្ចោះ មាន PoC Script ងាយស្រួលយល់ និងជួយផ្តល់ដំណោះស្រាយបច្ចេកទេសល្អ។
3. **Vulnerability Disclosure Programs (VDP / Points-only):**
   * សម្រាប់ក្រុមហ៊ុនដែលមិនទាន់មានថវិកាសម្រាប់សាច់ប្រាក់ អ្នកអាចបើកជាកម្មវិធី Points-Only ដោយផ្តល់នូវ Hall of Fame, Swag (អាវ, មួក, sticker) និងលិខិតសរសើរផ្លូវការ។
