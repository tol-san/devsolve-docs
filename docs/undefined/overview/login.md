# របៀប Login និងសុវត្ថិភាព

ការការពារគណនីរបស់អ្នកនៅលើ DevSolve គឺជាកត្តាចម្បងបំផុត ព្រោះគណនីរបស់អ្នកផ្ទុកនូវរបាយការណ៍ចន្លោះប្រហោងសំខាន់ៗ ទិន្នន័យសម្ងាត់ និងព័ត៌មានហិរញ្ញវត្ថុ/ប្រាក់រង្វាន់។

***

## 🔐 របៀប Login ចូលប្រព័ន្ធ

1. ចូលទៅកាន់គេហទំព័រ DevSolve ហើយចុចលើប៊ូតុង **Log In**។
2. បញ្ចូល **Email** ឬ **Username** និង **Password** របស់អ្នក។
3. ប្រសិនបើប្រព័ន្ធបានភ្ជាប់ជាមួយ Single Sign-On (SSO) ឬ Keycloak OAuth អ្នកអាចជ្រើសរើសចូលតាមរយៈ Identity Provider ដែលបានកំណត់។
4. ចុចប៊ូតុង **Sign In** ដើម្បីចូលទៅកាន់ Dashboard របស់អ្នក។

***

## 🔑 ករណីភ្លេចលេខសម្ងាត់ (Forgot Password)

ប្រសិនបើអ្នកភ្លេចលេខសម្ងាត់ សូមអនុវត្តដូចខាងក្រោម៖

1. នៅលើផ្ទាំង Login ចុចលើពាក្យ **"Forgot Password?"**។
2. បញ្ចូលអាសយដ្ឋានអ៊ីមែលដែលអ្នកបានចុះឈ្មោះ។
3. ប្រព័ន្ធនឹងផ្ញើ link សម្រាប់កំណត់លេខសម្ងាត់ឡើងវិញទៅកាន់អ៊ីមែលរបស់អ្នក។
4. បើកអ៊ីមែល ចុចលើ link នោះ ហើយបញ្ចូលលេខសម្ងាត់ថ្មីដែលមានសុវត្ថិភាពខ្ពស់។

***

## 🛡️ ការអនុវត្តល្អៗសម្រាប់សុវត្ថិភាពគណនី (Security Best Practices)

* **ប្រើប្រាស់លេខសម្ងាត់រឹងមាំ:** គួរមានប្រវែងចាប់ពី ១២ តួអក្សរឡើងទៅ ដោយលាយបញ្ចូលគ្នានូវអក្សរធំ អក្សរតូច លេខ និងនិមិត្តសញ្ញាពិសេស។
* **កុំប្រើលេខសម្ងាត់ដដែលៗ:** ជៀសវាងការប្រើលេខសម្ងាត់ដូចគ្នានឹងគណនីបណ្តាញសង្គម ឬគណនីអ៊ីមែលផ្ទាល់ខ្លួន។
* **ត្រួតពិនិត្យ Active Sessions:** ពិនិត្យមើល Sessions ដែលកំពុង Login ក្នុងទំព័រ Settings ជាប្រចាំ ប្រសិនបើឃើញឧបករណ៍ចម្លែក សូមចុច Logout ឧបករណ៍នោះជាបន្ទាន់។
* **រក្សាការសម្ងាត់នៃ Token:** មិនត្រូវចែករំលែក Session Cookie ឬ API Token ទៅកាន់អ្នកដទៃជាដាច់ខាត។
