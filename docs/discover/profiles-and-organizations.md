# Profile និងអង្គការ

Public Profile បង្ហាញ Identity និង Contribution ដែលអ្នកប្រើ ឬអង្គការបានជ្រើសរើស ឬត្រូវបានអនុញ្ញាតឱ្យបង្ហាញ។

## Researcher Profile

Profile អាចមាន Overview Statistics, Severity Breakdown, Biography, Location, Website, Social Links, Badges, Hacktivity, Community Posts, Hall of Thanks, Followers និង Following។ ជ្រើស **Follow** នៅពេល Sign in ដើម្បីបង្កើត Social Relationship។

## Organization Profile

Organization View អាចបង្ហាញ Identity, Verification State, Programs, Members និងព័ត៌មានសាធារណៈផ្សេងទៀត។ ម្ចាស់កែព័ត៌មានឯកជនពី Dashboard។

{% hint style="warning" %}
Verification បង្ហាញថា Platform បានអនុម័ត Organization Record ប៉ុណ្ណោះ។ អ្នកនៅតែត្រូវអាន Scope និង Rules របស់ Program នីមួយៗ។
{% endhint %}
