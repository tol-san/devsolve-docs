# ស្វែងរកកម្មវិធីសុវត្ថិភាព

Program កំណត់ Target ដែលអនុញ្ញាត Rules និងរង្វាន់ដែលអាចមានសម្រាប់ការរាយការណ៍ភាពងាយរងគ្រោះជាឯកជន។

{% hint style="info" %}
**អ្នកអាចមើលបាន:** គ្រប់គ្នា; ការដាក់ Report អាចតម្រូវឱ្យ Researcher បានអនុម័ត  
**ទីតាំង:** **Programs**
{% endhint %}

## ស្វែងរក Program

1. បើក **Programs**។
2. Search តាមឈ្មោះ Program ឬ Organization។
3. ប្រើ Filter ដូចជា Asset Type, Maximum Severity, Industry ឬ Reward Range។
4. ជ្រើស Sort ហើយបើក Program Card។

## អានព័ត៌មាន Program

- **Overview** — សេចក្តីពិពណ៌នា និងព័ត៌មានសំខាន់
- **Scope** — Assets ដែលអនុញ្ញាត និងមិនអនុញ្ញាត
- **Rules** — លក្ខខណ្ឌ Testing និង Disclosure
- **Bounty Matrix** — កម្រិតរង្វាន់ បើ Program មាន Bounty
- **Hall of Thanks** — Researcher ដែលបានទទួលការទទួលស្គាល់

{% hint style="danger" %}
កុំចាប់ផ្តើម Testing ដោយអានតែ Program Card។ ត្រូវផ្ទៀងផ្ទាត់ Asset និងសកម្មភាពជាក់លាក់ក្នុង Scope និង Rules បច្ចុប្បន្ន។
{% endhint %}

បើការដាក់ Report ត្រូវបានរារាំង ស្នើ Researcher Access ហើយតាមដាននៅ **Dashboard → My Access**។ Route ចាស់ `/program` មិនមែនជា Marketplace ទេ; ប្រើ `/programs`។
