# សំណួរអំពី Reports (Reports FAQ)

ខាងក្រោមនេះជាសំណួរ និងចម្លើយដែលសួរញឹកញាប់បំផុតទាក់ទងនឹងការ Submit និងគ្រប់គ្រងរបាយការណ៍ចន្លោះប្រហោងសុវត្ថិភាព។

---

## ❓ ១. Report "Pending / New" មានន័យដូចម្តេច?
* **ចម្លើយ:** ស្ថានភាព `Pending / New` មានន័យថារបាយការណ៍របស់អ្នកត្រូវបានបញ្ជូនចូលក្នុងប្រព័ន្ធដោយជោគជ័យ និងកំពុងស្ថិតក្នុងជួររង់ចាំ (Queue) ដើម្បីឱ្យក្រុមការងារ Triage របស់ក្រុមហ៊ុន ឬ DevSolve បើកពិនិត្យ និងផ្ទៀងផ្ទាត់ជំហាន PoC។

---

## ❓ ២. តើខ្ញុំអាច Edit ឬកែប្រែ Report បានទេក្រោយពេល Submit រួច?
* **ចម្លើយ:** ដើម្បីរក្សាតម្លាភាព និងកំណត់ពេលវេលាពិតប្រាកដ (Timestamp) នៃរបាយការណ៍ អ្នកមិនអាចកែប្រែអត្ថបទដើមរបស់ Report បានដោយផ្ទាល់នោះទេ។
* **ដំណោះស្រាយ:** ប្រសិនបើអ្នកចង់បន្ថែមព័ត៌មាន បញ្ជាក់ PoC ថ្មី ឬកែតម្រូវចំណុចខ្វះខាត សូម**សរសេរ Comment បន្ថែមនៅក្នុង Report នោះភ្លាមៗ**។ ក្រុមការងារ Triage នឹងអាន Comment របស់អ្នកមុនពេលធ្វើការសម្រេចចិត្ត។

---

## ❓ ៣. ចុះបើ Report របស់ខ្ញុំត្រូវបានចាត់ទុកជា "Duplicate"?
* **ចម្លើយ:** ប្រសិនបើ Report របស់អ្នកត្រូវបានបិទជា `Duplicate` មានន័យថាមាន Researcher ម្នាក់ផ្សេងទៀតបានរាយការណ៍ពីចន្លោះប្រហោងដូចគ្នានេះមុនអ្នករួចហើយ។
* **តើអ្នកណាបានប្រាក់រង្វាន់?** នៅលើ DevSolve យើងអនុវត្តគោលការណ៍ **First come, first served** — អ្នកដែលបាន Submit មុនគេតាម timestamp នឹងទទួលបាន Bounty។ Duplicate Report នឹងមិនប៉ះពាល់អវិជ្ជមានដល់ពិន្ទុ Reputation របស់អ្នកឡើយ។

---

## ❓ ៤. តើត្រូវធ្វើដូចម្តេចប្រសិនបើខ្ញុំចង់ដក (Withdraw) Report របស់ខ្ញុំវិញ?
* **ចម្លើយ:** ប្រសិនបើក្រោយពេល Submit អ្នកដឹងថាខ្លួនឯងយល់ច្រឡំ ឬ Bug នោះមិនមានហានិភ័យពិតប្រាកដ សូមសរសេរ Comment បញ្ជាក់ថា *"សូមស្នើសុំបិទ Report នេះ ដោយសារជា False Positive"*។ ក្រុមការងារនឹងបិទ Report នោះដោយមិនកាត់ពិន្ទុឡើយ។
