# របៀបបង្កើត និងគ្រប់គ្រង Program (Creating Programs)

ការបង្កើតកម្មវិធី Bug Bounty ច្បាស់លាស់នឹងទាក់ទាញ Security Researchers ដែលមានជំនាញខ្ពស់ និងកាត់បន្ថយរបាយការណ៍មិនពាក់ព័ន្ធ (Noise/False Positives)។

---

## 🛠️ ជំហានបង្កើត Program ថ្មី

ចូលទៅកាន់ **Program Management** (`/dashboard/program-management`) ហើយចុចលើប៊ូតុង **"Create Program"**៖

1. **ព័ត៌មានទូទៅ (General Information):**
   * **Program Name:** ឈ្មោះកម្មវិធី (ឧ. *Acme Corp Bug Bounty Program*)
   * **Tagline & Summary:** ការពន្យល់សង្ខេបពីគោលបំណងនៃកម្មវិធី
   * **Program Logo / Banner:** រូបភាពតំណាងកម្មវិធី
2. **ប្រភេទនៃកម្មវិធី (Program Visibility):**
   * **Public:** បង្ហាញជាសាធារណៈលើគេហទំព័រសម្រាប់ Researcher ទាំងអស់។
   * **Private:** អនុញ្ញាតសម្រាប់តែ Researcher ដែលទទួលបានការអញ្ជើញប៉ុណ្ណោះ។
3. **គោលការណ៍ណែនាំ (Program Policy):**
   * បញ្ជាក់ច្បាស់ពីច្បាប់នៃការធ្វើតេស្ត, Safe Harbor Policy និងលក្ខខណ្ឌនៃការផ្ញើ Report។
4. **កំណត់ Scope & Rewards:** (សូមមើលទំព័រ Scope & Rewards បន្ថែម)។
5. ចុច **Save as Draft** ឬ **Submit for Review** ដើម្បីឱ្យ Admin ពិនិត្យមុននឹង Publish។

---

## 🔄 វដ្តជីវិតនៃការគ្រប់គ្រង Program

* **Draft:** កម្មវិធីកំពុងស្ថិតក្នុងការរៀបចំ មិនទាន់បើកជាសាធារណៈ។
* **Under Review:** កំពុងរង់ចាំ Admin ពិនិត្យមើលលក្ខខណ្ឌ និង Scope។
* **Published / Active:** កម្មវិធីកំពុងដំណើរការពេញលេញ អាចទទួល Reports បាន។
* **Paused:** ផ្អាកការទទួល Reports ជាបណ្តោះអាសន្ន (ឧ. ពេលក្រុមហ៊ុនកំពុងជាប់ដៃជួសជុលបញ្ហាចាស់ៗច្រើន)។
* **Closed:** បិទបញ្ចប់កម្មវិធីជាស្ថាពរ។
