# ការចូលរួមក្នុងសហគមន៍ (Community Features)

DevSolve មិនត្រឹមតែជាកន្លែងស្វែងរក Bug ប៉ុណ្ណោះទេ ប៉ុន្តែជាសហគមន៍សុវត្ថិភាពឌីជីថលដ៏រស់រវើក ដែលអ្នកអាចចែករំលែកចំណេះដឹង បង្ហាញសមិទ្ធផល និងរៀនសូត្រពីអ្នកដទៃ។

---

## ⚡ ១. Hacktivity Feed

ទំព័រ **[Hacktivity](/hacktivity)** គឺជាផ្ទាំងព័ត៌មានបន្តផ្ទាល់ដែលបង្ហាញពី៖
* របាយការណ៍ចន្លោះប្រហោងដែលត្រូវបានដោះស្រាយ (Resolved) និងបានបើកបង្ហាញជាសាធារណៈ (Publicly Disclosed) ដោយមានការយល់ព្រមពីក្រុមហ៊ុន។
* Timeline នៃ Bounties ដែលត្រូវបានបើកផ្តល់ជូនក្នុងសហគមន៍។
* នេះជាប្រភពចំណេះដឹងដ៏ល្អបំផុតដើម្បីរៀនពីវិធីសាស្ត្រវាយលុកថ្មីៗ (Attack Vectors) និងរបៀបដែលអ្នកដទៃសរសេរ Report ប្រកបដោយជោគជ័យ។

---

## 🏅 ២. Leaderboard & Rankings

ទំព័រ **[Leaderboard](/leaderboard)** បង្ហាញពីចំណាត់ថ្នាក់របស់ Security Researchers ទូទាំងពិភពលោក៖
* ចំណាត់ថ្នាក់តាមខែ (Monthly), តាមត្រីមាស (Quarterly), និងគ្រប់ពេលវេលា (All-Time)។
* ចំណាត់ថ្នាក់គិតផ្អែកលើ **Reputation Points** និងចំនួន **Valid Vulnerabilities** ដែលបានរកឃើញ។
* ការជាប់ឈ្មោះក្នុង Top 10 ឬ Top 50 នឹងទាក់ទាញចំណាប់អារម្មណ៍ពីក្រុមហ៊ុនធំៗសម្រាប់ការអញ្ជើញចូលរួម Private Programs ឬការផ្តល់ឱកាសការងារផ្នែក Cybersecurity។

---

## 💬 ៣. Discussions & Forum

ទំព័រ **[Discussions Hub](/discussions)** គឺជាវេទិកាសួរ-ឆ្លើយ និងពិភាក្សា៖
* បង្កើតប្រធានបទពិភាក្សាអំពី Web Security, Mobile Pentesting, Cloud Security, ឬ API Hacking។
* បោះឆ្នោតគាំទ្រ (Upvote / Downvote) លើសំណួរ ឬចម្លើយដែលមានប្រយោជន៍។
* ជួយដោះស្រាយចម្ងល់របស់អ្នកដទៃ ដើម្បីបង្កើតបណ្តាញទំនាក់ទំនងក្នុងវិស័យសុវត្ថិភាព។

---

## 🚀 ៤. Showcases

ទំព័រ **[Showcases](/showcases)** គឺជាកន្លែងសម្រាប់បង្ហាញស្នាដៃ និងសមត្ថភាពផ្ទាល់ខ្លួន៖
* អ្នកអាចសរសេរបង្ហោះ Writeup បទពិសោធន៍នៃការរកឃើញ Bug ពិសេសៗ (ដែលត្រូវបានអនុញ្ញាតឱ្យផ្សាយ)។
* បង្ហាញ Open-Source Security Tools, Automation Scripts, ឬ Extension ដែលអ្នកបានបង្កើតឡើង។
* ទទួលការគាំទ្រ និង Comment កោតសរសើរពីសមាជិកដទៃទៀតក្នុងសហគមន៍។
