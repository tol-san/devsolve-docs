# សកម្មភាពហាមឃាត់ដាច់ខាត (Prohibited Activities)

DevSolve មានគោលជំហរម៉ឺងម៉ាត់បំផុតក្នុងការទប់ស្កាត់រាល់សកម្មភាពដែលមានចេតនាព្យាបាទ ឬបង្កការខូចខាតដល់ប្រព័ន្ធ។

---

## 🚫 បញ្ជីសកម្មភាពដែលត្រូវហាមឃាត់ដាច់ខាត

1. **Denial of Service (DoS / DDoS):**
   * ការបាញ់ Flood traffic, Stress testing, ឬការធ្វើឱ្យប្រព័ន្ធ Server គាំង ឬដំណើរការយឺតប៉ះពាល់ដល់អ្នកប្រើប្រាស់ទូទៅ។
2. **Social Engineering & Phishing:**
   * ការបន្លំផ្ញើអ៊ីមែល ឬទូរស័ព្ទទៅកាន់បុគ្គលិក អតិថិជន ឬដៃគូរបស់ក្រុមហ៊ុនដើម្បីលួច Password ឬព័ត៌មានសម្ងាត់។
3. **ការបំផ្លាញ ឬកែប្រែទិន្នន័យ (Data Destruction / Modification):**
   * ការលុប Records ក្នុង Database, ការកែប្រែសមតុល្យគណនីរបស់អ្នកដទៃ, ឬការ Deface គេហទំព័រ។
4. **ការទាញយកទិន្នន័យលើសពីការចាំបាច់ (Mass Data Exfiltration):**
   * នៅពេលរកឃើញចន្លោះប្រហោងទិន្នន័យ អ្នកត្រូវបានអនុញ្ញាតឱ្យបង្ហាញភស្តុតាងត្រឹមតែ record តូចមួយប៉ុណ្ណោះ។ ការទាញយកទិន្នន័យរាប់ពាន់ ឬរាប់លាន records ត្រូវបានចាត់ទុកជាបទល្មើសព្រហ្មទណ្ឌ។
5. **ការគំរាមកំហែង និងជំរិតទារប្រាក់ (Extortion & Ransom):**
   * ការទាមទារប្រាក់រង្វាន់ក្រៅប្រព័ន្ធ DevSolve ឬគំរាមថានឹងទម្លាយទិន្នន័យជាសាធារណៈប្រសិនបើមិនព្រមឱ្យលុយ។

---

## ⚖️ វិធានការចំពោះការបំពាន

បុគ្គលណាដែលប្រព្រឹត្តល្មើសនឹងសកម្មភាពខាងលើ នឹងត្រូវទទួលរង៖
* ការបិទគណនី DevSolve ជាអចិន្ត្រៃយ៍ និងរឹបអូសប្រាក់សមតុល្យដែលមាន។
* ការដកហូតការការពារ Safe Harbor (អាចប្រឈមមុខនឹងការប្តឹងផ្តល់ពីក្រុមហ៊ុនរងគ្រោះ)។
* ការបញ្ជូនរបាយការណ៍ស៊ើបអង្កេតទៅកាន់អាជ្ញាធរមានសមត្ថកិច្ចផ្នែកប្រឆាំងបទល្មើសបច្ចេកវិទ្យា។
