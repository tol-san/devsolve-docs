# គោលការណ៍ Responsible Disclosure

គោលការណ៍នៃការរាយការណ៍ដោយការទទួលខុសត្រូវ (Responsible Disclosure ឬ Coordinated Vulnerability Disclosure - CVD) គឺជាគ្រឹះនៃទំនុកចិត្តរវាងអ្នកស្រាវជ្រាវសុវត្ថិភាព និងក្រុមហ៊ុននានាលើ DevSolve។

---

## 🤝 គោលការណ៍ជាមូលដ្ឋាន

1. **ការរក្សាការសម្ងាត់ (Confidentiality):**
   * នៅពេលអ្នករកឃើញចន្លោះប្រហោងសុវត្ថិភាព អ្នកត្រូវតែរាយការណ៍តាមរយៈ DevSolve ដោយសម្ងាត់ជាមុនសិន។
   * មិនត្រូវផ្សព្វផ្សាយជាសាធារណៈលើបណ្តាញសង្គម (Facebook, X, LinkedIn, Telegram) ឬចែករំលែកជាមួយភាគីទីបី មុនពេលក្រុមហ៊ុនបានជួសជុលបញ្ហារួចរាល់ជាដាច់ខាត។

2. **ពេលវេលាសមស្របសម្រាប់ក្រុមហ៊ុនជួសជុល (Remediation Window):**
   * ក្រុមហ៊ុនត្រូវការពេលវេលាដើម្បីសរសេរកូដ តេស្ត និង Deploy patch។ រយៈពេលស្តង់ដារគឺ **៩០ ថ្ងៃ** (ឬខ្លីជាងនេះអាស្រ័យលើការព្រមព្រៀងគ្នារវាងភាគីទាំងពីរ)។

---

## 📢 ដំណើរការនៃការស្នើសុំ Public Disclosure

នៅពេលដែលក្រុមហ៊ុនបានជួសជុលបញ្ហារួចរាល់ (Status: `Resolved`):
1. Researcher ឬ Company អាចចុចលើប៊ូតុង **"Request Disclosure"**។
2. ប្រភេទនៃការបើកបង្ហាញមានពីរ៖
   * **Full Disclosure:** បើកបង្ហាញរបាយការណ៍ទាំងស្រុង រួមទាំងជំហាន PoC និងកូដគំរូ។
   * **Limited / Redacted Disclosure:** បើកបង្ហាញតែចំណងជើង និងទិដ្ឋភាពទូទៅនៃ Bug ដោយលាក់បាំងនូវទិន្នន័យសម្ងាត់ (Redacted sensitive URLs/payloads)។
3. ការបើកបង្ហាញជាសាធារណៈ (Public Disclosure) នឹងត្រូវផ្សាយលើទំព័រ **Hacktivity** បាន លុះត្រាតែមាន**ការយល់ព្រមពីភាគីទាំងពីរ (Mutual Agreement)**។
