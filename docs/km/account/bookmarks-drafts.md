# Bookmarks & Saved Drafts

ដើម្បីជួយសម្រួលដល់ដំណើរការស្រាវជ្រាវប្រចាំថ្ងៃ DevSolve ផ្តល់នូវឧបករណ៍ពីរគឺ Bookmarks និង Saved Drafts។

---

## 🔖 ការប្រើប្រាស់ Bookmarks

* នៅពេលអ្នកឃើញ Bounty Program ដែលអ្នកពេញចិត្ត ប៉ុន្តែមិនទាន់មានពេលធ្វើតេស្តភ្លាមៗ សូមចុចលើរូប **Bookmark icon** នៅលើកាត Program នោះ។
* ដើម្បីមើល Programs ទាំងអស់ដែលអ្នកបានរក្សាទុក សូមចូលទៅកាន់ **[My Bookmarks](/dashboard/bookmarks)** ក្នុង Sidebar។
* អ្នកក៏អាច Bookmark ប្រធានបទ Discussions សំខាន់ៗដើម្បីទុកអានឡើងវិញបានផងដែរ។

---

## 📝 ការគ្រប់គ្រង Saved Drafts

* នៅពេលសរសេរ Report ប្រសិនបើអ្នកមិនទាន់មានពេលគ្រប់គ្រាន់ដើម្បីរៀបចំ PoC វីដេអូ ឬ cURL command ឱ្យបានពេញលេញ អ្នកអាចចុច **"Save as Draft"**។
* ចូលទៅកាន់ **[Saved Drafts](/dashboard/saved-draft)** ដើម្បី៖
  * បើកមើលបញ្ជី Drafts ដែលមិនទាន់បាន Submit
  * ចុច Edit ដើម្បីសរសេរបន្ថែម
  * ចុច Delete ប្រសិនបើចន្លោះប្រហោងនោះមិនមានហានិភ័យពិតប្រាកដ
  * ចុច Submit ទៅកាន់ក្រុមហ៊ុននៅពេលរួចរាល់ ១០០%
