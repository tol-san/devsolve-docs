# Notifications (ប្រព័ន្ធជូនដំណឹង)

ការទទួលបានដំណឹងទាន់ពេលវេលាធានាថាអ្នកមិនខកខានការឆ្លើយតបសំខាន់ៗអំពីរបាយការណ៍ចន្លោះប្រហោង ឬការបើកប្រាក់រង្វាន់ឡើយ។

---

## 🔔 ប្រភេទនៃការជូនដំណឹង

DevSolve ផ្តល់ការជូនដំណឹងតាមពីរមធ្យោបាយ៖
1. **In-App Notifications:** បង្ហាញនៅរូបកណ្តឹង (Bell icon) ជ្រុងខាងស្តាំខាងលើ ឬចូលទៅកាន់ `/dashboard/notifications`។
2. **Email Notifications:** ផ្ញើដោយផ្ទាល់ទៅកាន់អ៊ីមែលដែលអ្នកបានចុះឈ្មោះ។

---

## 📩 ព្រឹត្តិការណ៍ដែលប្រព័ន្ធនឹងជូនដំណឹង

* **Report Updates:** នៅពេលដែល Report របស់អ្នកត្រូវបានផ្លាស់ប្តូរ Status (ពី Pending ➔ Triaged ➔ Resolved)។
* **Comments:** នៅពេលដែល Triager ឬក្រុមហ៊ុនសរសេរ Comment សាកសួរព័ត៌មានបន្ថែម។
* **Bounty Awarded:** នៅពេលដែលក្រុមហ៊ុនបានផ្ទេរប្រាក់រង្វាន់ចូល Wallet របស់អ្នក។
* **Program Updates:** នៅពេលដែល Program ដែលអ្នកបាន Bookmark មានការផ្លាស់ប្តូរ Scope ឬតារាងរង្វាន់។
* **Community Interactions:** នៅពេលមានអ្នក Upvote ឬ Comment លើ Discussion/Showcase របស់អ្នក។
