# ប្រភេទគណនី (Account Types)

នៅលើ DevSolve ប្រព័ន្ធត្រូវបានរៀបចំឡើងដើម្បីបម្រើអ្នកប្រើប្រាស់ ៣ ប្រភេទសំខាន់ៗ ទៅតាមតួនាទី និងគោលបំណង៖

---

## 🧑‍💻 ១. Security Researcher / Developer (អ្នកស្រាវជ្រាវ)

គណនីប្រភេទនេះស័ក្តិសមសម្រាប់ Ethical Hackers, Penetration Testers, សិស្សនិស្សិត និង Developers ដែលចង់ធ្វើតេស្តស្វែងរកចន្លោះប្រហោងសុវត្ថិភាព។

**សិទ្ធិ និងមុខងារសំខាន់ៗ៖**
* ចូលមើល និងស្វែងរក Bug Bounty Programs ទាំង Public និង Private។
* បង្កើត និងផ្ញើរបាយការណ៍ចន្លោះប្រហោងសុវត្ថិភាព (Submit Vulnerability Reports)។
* តាមដានស្ថានភាពរបាយការណ៍ និងឆ្លើយឆ្លងជាមួយក្រុមហ៊ុន។
* ទទួលបានប្រាក់រង្វាន់ (Bounties) និងកសាងពិន្ទុកេរ្តិ៍ឈ្មោះ (Reputation Points)។
* ចូលរួមក្នុងសហគមន៍៖ បង្កើត Showcases, ចូលរួម Discussions, និងមើល Leaderboard។

---

## 🏢 ២. Company / Organization (ក្រុមហ៊ុន ឬស្ថាប័ន)

គណនីប្រភេទនេះសម្រាប់ក្រុមហ៊ុន ធនាគារ សហគ្រាស ឬ Startup ដែលចង់ការពារផលិតផលឌីជីថលរបស់ខ្លួន។

**សិទ្ធិ និងមុខងារសំខាន់ៗ៖**
* ស្នើសុំផ្ទៀងផ្ទាត់អត្តសញ្ញាណក្រុមហ៊ុន (Company Verification Badge)។
* បង្កើត និងគ្រប់គ្រង Bug Bounty Programs (កំណត់ Scope, Policy និងកម្រិតរង្វាន់)។
* ទទួល និងត្រួតពិនិត្យរបាយការណ៍ចន្លោះប្រហោង (Triage Inbox)។
* ផ្លាស់ប្តូរ Status នៃ Report (Triaged, Resolved, Duplicate, Informative)។
* អនុម័ត និងផ្ទេរប្រាក់រង្វាន់ (Bounty Payout) ជូន Researcher។
* អញ្ជើញ និងគ្រប់គ្រងសមាជិកក្រុមការងារ (Team Management: Admins, Triagers)។

---

## 🛡️ ៣. Platform Administrator (អ្នកគ្រប់គ្រងប្រព័ន្ធ)

គណនីដែលគ្រប់គ្រងដោយផ្ទាល់ដោយក្រុមការងារ DevSolve ដើម្បីធានានូវតម្លាភាព សុវត្ថិភាព និងភាពត្រឹមត្រូវក្នុង Platform។

**ភារកិច្ចចម្បង៖**
* ពិនិត្យ និងអនុម័តការផ្ទៀងផ្ទាត់របស់ក្រុមហ៊ុន (Company Verification)។
* ត្រួតពិនិត្យគុណភាព និងអនុម័ត Bounty Programs មុនពេល Publish ជាសាធារណៈ។
* សម្រុះសម្រួលជម្លោះ (Mediation) រវាង Researcher និង Company ក្នុងករណីមានការមិនចុះសម្រុង។
* ត្រួតពិនិត្យខ្លឹមសារសហគមន៍ (Content Moderation) និងការពារប្រឆាំង Spam។
