# Settings & Security

Manage your account profile, notification preferences, security credentials, and active device sessions from a centralized dashboard.

---

## ⚙️ Account Preferences

Access your settings interface at `/dashboard/profile/settings`:
* **Personal & Contact Records:** Update primary legal names, communication email addresses, and local time zones.
* **Notification Rules:** Configure granular toggles for marketing dispatches, daily digests, and real-time security alerts.

---

## 🛡️ Security & Authentication

* **Password Rotation:** Periodically update account passwords using strong, randomly generated strings.
* **Two-Factor Authentication (2FA):** Enforce time-based one-time password (TOTP) 2FA using authenticators such as Google Authenticator, Bitwarden, or 1Password.
* **Active Session Management:** Inspect real-time client IP addresses, geolocations, and browser fingerprints. Click **"Revoke Session"** or **"Terminate All Other Sessions"** if unauthorized activity is suspected.
