# Platform Security Incidents

<a href="https://docs.devsolve.app/en/administration/security-incidents" class="button secondary">🇬🇧 English</a>

Administrative Security Incidents ជួយ Monitor Organization Account/Security States និង Incident Details។

1. បើក **Dashboard → Security Incidents**។
2. Search ឬ Filter Records។
3. បើក Detail ហើយពិនិត្យ Organization, Timestamps, Evidence និង Current State។
4. សម្របសម្រួល Response តាម Internal Procedure។
5. Apply តែ Supported និង Authorized Action។

Frontend ស្គាល់ State ដូចជា **Active**, **Suspended**, **Banned**, **Pending**, **Removed**។ State ទាំងនេះខុសពី Community Moderation Status និង Vulnerability Report Status។
