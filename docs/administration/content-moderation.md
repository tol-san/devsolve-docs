# ការត្រួតពិនិត្យមាតិកា

**Content Management** គ្រប់គ្រង Problems, Solutions និង Showcases; **Content Reports** គ្រប់គ្រង Flags ពីអ្នកប្រើ។

1. បើក **Content Management** ហើយជ្រើស Content Type។
2. Filter តាម Pending ឬ Review State ផ្សេង។
3. បើក Item ពេញ រួមទាំង Attachments និង Links។
4. ពិនិត្យ Relevance, Readability, Prohibited Content, Secrets, Personal Data និង Unsafe Security Detail។
5. Approve/Publish ឬ Reject តាម Control របស់ Content Type។

Problem Moderation ប្រើ Publish ឬ Reject។ Solutions និង Showcases ប្រើ Pending, Approved, Rejected; Showcase Rejection ត្រូវមាន Reason។ AI Auto-Approval អាច Process Target ដែលបាន Configure ប៉ុន្តែ Administrator ត្រូវ Monitor Outcome។

សម្រាប់ Flag បើក **Content Reports**, ពិនិត្យ Reason និង Target ហើយ Resolve ឬ Dismiss។ ប្រើ **Moderation Log** ដើម្បីមើល Recorded Actions។
