# Categories, Tags, Weaknesses និង Auto-Approval

<a href="https://docs.devsolve.app/en/administration/taxonomy-and-automation" class="button secondary">🇬🇧 English</a>

Taxonomy ធ្វើឱ្យ Community និង Report Classification អាចស្វែងរក និងស្របគ្នា។

## Categories

ប្រើ **Categories** ដើម្បី Search, Filter, Create, Edit, Activate/Deactivate និងគ្រប់គ្រង Icon។ កំណត់ Name, Slug, Scope និង Sort Order ឱ្យច្បាស់។

## Tags

ប្រើ **Tags** ដើម្បីថែទាំ Community Topics ដែលអាចប្រើឡើងវិញ។ ជៀសវាង Near-duplicate Tags។

## Weaknesses

ប្រើ **Weaknesses** ដើម្បីគ្រប់គ្រង Vulnerability Classification Catalogue។ រក្សា Standard Identifier និង Description ឱ្យត្រឹមត្រូវ។

## AI Auto-Approval

ប្រើ **AI Auto-Approval** ដើម្បី Enable/Disable Automated Decision តាម Supported Target Type។ Audit False Approval, False Rejection និង Pending Items ជាប្រចាំ។
