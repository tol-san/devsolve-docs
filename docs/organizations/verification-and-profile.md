# ការផ្ទៀងផ្ទាត់ និង Profile អង្គការ

<a href="https://docs.devsolve.app/en/organizations/verification-and-profile" class="button secondary">🇬🇧 English</a>

បំពេញ Organization Record និង Verification មុនពឹងផ្អែកលើ Public Program Operations។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** Organization Owner  
**ទីតាំង:** Dashboard Organization Card/Settings
{% endhint %}

Interface ស្គាល់ State ដូចជា **Pending**, **Active**, **Rejected** និង **Suspended**។ Pending ឬ Rejected អាចកំណត់ Actions រហូតដល់អង្គការកែព័ត៌មានដែលបានស្នើ។

## កែ Profile

1. បើក Organization Settings ហើយជ្រើស Edit។
2. ពិនិត្យ Name, Domain, Website, Industry, Company Size, Country/Region និង Description។
3. Upload ឬ Link Logo និង Cover Banner។
4. Save ហើយកែ Validation Error។
5. ត្រឡប់ទៅ Organization View និងបញ្ជាក់លទ្ធផល។

Platform Administrator Review Verification។ បើមាន Resubmit Action ត្រូវកែព័ត៌មានជាមុន រួច Resubmit។
