# គ្រប់គ្រង Researcher Access

Researcher Access កំណត់អ្នកខាងក្រៅដែលអាច Report ទៅ Programs របស់អង្គការ។

{% hint style="info" %}
**សិទ្ធិចាំបាច់:** `MANAGE_RESEARCHERS`  
**ទីតាំង:** **Dashboard → Researcher Access**
{% endhint %}

1. បើក Access Queue។
2. Review Public Identity និង Background របស់ Researcher។
3. Approve តែនៅពេលស្រប Access Policy។
4. Reject ដោយ Decision ត្រឹមត្រូវ ប្រសិនបើមិនគួរផ្តល់សិទ្ធិ។
5. ពិនិត្យ Active Researchers ជាប្រចាំ និង Revoke នៅពេលចាំបាច់។

អង្គការក៏អាច Invite Researcher ដោយ Identifier និង Note។ Reporting Access ខុសពី Internal Team Invitation។ Access មួយអនុវត្តលើ Programs របស់អង្គការ ប៉ុន្តែមិនជំនួស Scope, Rules, Status ឬ Dates របស់ Program នីមួយៗទេ។
