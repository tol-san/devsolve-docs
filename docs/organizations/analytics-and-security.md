# Analytics និង Security Incidents

## Analytics

សម្រាប់ Account ដែលមាន Organization Membership បើក **Dashboard** ដើម្បី Load Analytics របស់ Active Organization។ ជ្រើស All Programs ឬ Program មួយ និង Time Range។ ទិន្នន័យអាចមាន Report Totals, Accepted/Rejected Outcomes, Severity Distribution, Submission Trend, SLA Indicators, Targeted Assets, Top Weaknesses, Researcher Ranking, Programs និង Recent Reports។

Empty Chart មានន័យថាគ្មានទិន្នន័យត្រឡប់សម្រាប់ Selection នោះ មិនមែនជាភស្តុតាងថាគ្មាន Security Activity ទេ។ ប្រើ **Refresh** ក្រោយប្តូរ Active Workspace ឬ Service Error។ Standalone `/dashboard/analytics` Prototype ប្រើ Fallback Values ហើយមិនមែនជា Production Reporting Source ទេ; កុំប្រើ Totals ឬ Export Control របស់វាសម្រាប់ Business Decision។

## Organization Security Incidents

Member ដែលមាន Triage Permission អាចបើក **Security Incidents**, Filter List និងពិនិត្យ Detail។ អនុវត្ត Internal Incident Response Procedure ហើយកុំដាក់ Secret ឬ Personal Data ក្នុង Public Community Content។
