# Analytics និង Security Incidents

<a href="/en/organizations/analytics-and-security" class="button secondary">English</a>

## Analytics

បើក **Dashboard → Analytics** ហើយជ្រើស All Programs ឬ Program មួយ។ ទិន្នន័យអាចមាន Report Totals, Accepted/Rejected Outcomes, Severity Distribution, Submission Trend, SLA Indicators, Targeted Assets, Top Weaknesses, Researcher Ranking, Programs និង Recent Reports។

Empty Chart មានន័យថាគ្មានទិន្នន័យត្រឡប់សម្រាប់ Selection នោះ មិនមែនជាភស្តុតាងថាគ្មាន Security Activity ទេ។ ផ្ទៀងផ្ទាត់ Export ក្នុង Deployment មុនប្រើជាផ្លូវការ។

## Organization Security Incidents

Member ដែលមាន Triage Permission អាចបើក **Security Incidents**, Filter List និងពិនិត្យ Detail។ អនុវត្ត Internal Incident Response Procedure ហើយកុំដាក់ Secret ឬ Personal Data ក្នុង Public Community Content។
