# ច្បាប់ Community និងគុណភាព Report

<a href="https://docs.devsolve.app/en/policies/community-and-report-rules" class="button secondary">🇬🇧 English</a>

## Community Content

- ប្រើ Title ច្បាស់ និង Context គ្រប់គ្រាន់។
- Search Duplicate មុន Post។
- ផ្តល់ Credit និង Link ទៅ Source ដោយសុវត្ថិភាព។
- កុំ Publish Secrets, Credentials, Personal Data, Harassment, Spam ឬ Uncoordinated Vulnerability Detail។
- ពន្យល់ Code និងសម្អាត Logs/Screenshots។

## Problems, Solutions និង Showcases

Problem ត្រូវមាន Type និង Category ត្រឹមត្រូវ; Bug ត្រូវមាន Expected/Actual Behavior និង Reproduction Steps។ Solution ត្រូវបញ្ជាក់ Approach, Verification, Tested Versions និង Trade-offs។ Showcase ត្រូវមាន Purpose, Steps, Technology Stack និង Resources ហើយមានសិទ្ធិចែករំលែកមាតិកានោះ។

## Vulnerability Reports

បញ្ជាក់ Scope, ពិពណ៌នា Impact, ផ្តល់ Reproducible Evidence, ជៀសវាង Destructive Payload, ដក Real PII និងគោរព Program Disclosure Rules។
