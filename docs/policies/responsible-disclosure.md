# Responsible Disclosure

Responsible Disclosure រក្សា Sensitive Finding ជាឯកជន ខណៈ Organization ផ្ទៀងផ្ទាត់ និងដោះស្រាយ។

## កាតព្វកិច្ច Researcher

- Test តែ In-Scope Asset និង Technique ដែលអនុញ្ញាត។
- កំណត់ Access ឱ្យតិចបំផុត ហើយបញ្ឈប់ពេលមាន Evidence គ្រប់គ្រាន់។
- កុំរក្សា បង្ហាញ ឬកែ Real User Data។
- Submit តាម Private Report Workflow។
- រក្សាការទំនាក់ទំនងឱ្យត្រឹមត្រូវ និងមានវិជ្ជាជីវៈ។

## កាតព្វកិច្ច Organization

- ផ្សព្វផ្សាយ Scope, Exclusions, Rules និង Contact Expectations ច្បាស់លាស់។
- Acknowledge និង Triage Reports ដោយយុត្តិធម៌។
- ការពារ Researcher Identity និង Evidence។
- គោរព Reward និង Recognition Commitment ដែលបាន Publish។

Public Disclosure អនុញ្ញាតតែនៅពេល Program Policy និង Agreement ពាក់ព័ន្ធអនុញ្ញាត។ Community Problem ឬ Showcase មិនអាចជំនួស Coordinated Disclosure ទេ។
