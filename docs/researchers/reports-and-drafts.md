# Reports និង Saved Drafts

ប្រើ **Reports** ដើម្បីតាមដាន Findings ដែលបាន Submit និង **Saved Drafts** ដើម្បីបន្ត Submission ដែលមិនទាន់បញ្ចប់។

## ស្វែងរក Report

1. បើក **Dashboard → Reports**។
2. Search តាម Report, Program ឬ Text ដែលមាន។
3. Filter តាម Status, Severity ឬ Program។
4. បើក Report Card ដើម្បីមើល Detail។

Detail Page អាចមាន Target, Classification, Description, Impact, Reproduction Steps, PoC, Remediation, References, Attachments, Comments, Activity, Rewards និង Retest History។ Field ដែលគ្មានទិន្នន័យត្រូវបានលាក់ មិនត្រូវបង្កើតព័ត៌មានស្មានទេ។

## ប្រើ Drafts

Report Form រក្សា Server-backed Draft នៅពេលគាំទ្រ ហើយអាចស្នើឱ្យ Resume Draft ចាស់សម្រាប់ Program ដូចគ្នា។ បើក **Dashboard → Saved Drafts**, ពិនិត្យ Type និង Title ហើយជ្រើស Resume។ Delete តែនៅពេលប្រាកដថាមិនត្រូវការទៀត។

Community Problem ក៏អាចមាន Draft ដូច្នេះ Saved Drafts អាចមានមាតិកាច្រើនប្រភេទ។
