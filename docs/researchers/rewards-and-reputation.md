# រង្វាន់ កេរ្តិ៍ឈ្មោះ និងការទទួលស្គាល់

DevSolve បែងចែក Organization Bounty, Platform Reputation និង Hall of Thanks Recognition។

| Item | អត្ថន័យ |
| --- | --- |
| Bounty reward | ប្រាក់ដែល Organization កត់សម្រាប់ Report ដែលមានសិទ្ធិ |
| Reputation points | ពិន្ទុ Platform សម្រាប់ Valid Finding Outcome ដែលគាំទ្រ |
| Recognition | ការអរគុណម្តងពី Organization សម្រាប់ Resolved Report ដែលមានសិទ្ធិ |
| Hall of Thanks | ការបង្ហាញ Recognition Record ជាសាធារណៈ |

Leaderboard ផ្អែកលើ Reputation មិនមែន Payout Size ទេ។ Reputation ដែលរក្សាទុកមិនត្រូវបានគណនាឡើងវិញពី Severity ដែលកែពេលក្រោយទេ។

{% hint style="warning" %}
ទំព័រ **Dashboard → Rewards** បច្ចុប្បន្នប្រើ Demonstration Data។ Totals, Payout Status, Export Button និង Sample Transactions មិនមែនជា Real Balance ឬ Payment Commitment ទេ។
{% endhint %}
