# បង្កើត និងគ្រប់គ្រង Showcase

<a href="/en/community/showcases" class="button secondary">English</a>

Showcase គឺជាការបង្ហាញ Project, Architecture ឬ Technical Build Guide ជាសាធារណៈ និងមានរចនាសម្ព័ន្ធ។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** អ្នក Sign in  
**ទីតាំង:** **Community → Start a discussion → Showcase Project**
{% endhint %}

## បង្កើត Showcase

{% stepper %}
{% step %}
### ណែនាំ Project

បន្ថែម Cover Image, Title, Summary, Category និង Technology Stack។
{% endstep %}

{% step %}
### បន្ថែម Project Links

បន្ថែម `https://` Links ដូចជា Repository, Live Demo ឬ Walkthrough Video។
{% endstep %}

{% step %}
### បង្កើត Build Steps

បន្ថែម Title និង Explanation សម្រាប់ជំហាននីមួយៗ។ អ្នកអាចបន្ថែម Screenshot, Code Snippet ឬ Diagram ហើយ Duplicate, Reorder ឬ Remove Steps។
{% endstep %}

{% step %}
### បន្ថែម Resources

បន្ថែម Links ដែលមាន Label ដូចជា Design File, Documentation, Article ឬ Repository។
{% endstep %}

{% step %}
### ពិនិត្យ និងដាក់ស្នើ

ពិនិត្យ Preview ហើយ Submit for Moderation។ Showcase មិនទាន់ Public ទេ រហូតដល់បានអនុម័ត។
{% endstep %}
{% endstepper %}

Diagram Builder មាន Templates, Editable Nodes និង Connectors សម្រាប់ Data Model, Class, Flow និង Architecture។ ពិនិត្យអក្សរឱ្យអានបាន មុន Save។

Showcase មាន Status **Pending**, **Approved** ឬ **Changes requested/Rejected**។ បើមានការស្នើឱ្យកែ បើកពី **My Community**, កែតាម Reason ហើយ Submit Revision។
