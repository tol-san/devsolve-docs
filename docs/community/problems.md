# បង្កើត និងគ្រប់គ្រង Problem

<a href="https://docs.devsolve.app/en/community/problems" class="button secondary">🇬🇧 English</a>

Problem គឺជាការស្នើសុំជំនួយពី Community អំពីបញ្ហាបច្ចេកទេស។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** អ្នកដែល Sign in  
**ទីតាំង:** **Community → Start a discussion → Problem & Bug**
{% endhint %}

## ជ្រើស Problem Type

| Type | ប្រើសម្រាប់ |
| --- | --- |
| Bug | ឥរិយាបថមិនត្រឹមត្រូវដែលអាចបង្ហាញឡើងវិញបាន |
| How-to | មានគោលដៅ ប៉ុន្តែមិនដឹងវិធីអនុវត្ត |
| Architecture | សំណួរអំពី System Structure ឬ Component Boundary |
| Performance | Software ដំណើរការ ប៉ុន្តែយឺត ឬចំណាយធនធានខ្ពស់ |
| Security | សំណួរ Hardening ឬ Authentication ដែលសមស្របសម្រាប់សាធារណៈ |
| Deployment | Build, Pipeline, Environment និង Release |
| General | បញ្ហាបច្ចេកទេសក្រៅប្រភេទខាងលើ |

## បង្កើត Problem

{% stepper %}
{% step %}
### ពិពណ៌នាបញ្ហា

បញ្ចូល Title ច្បាស់ 10–180 តួអក្សរ ជ្រើស Category និង Problem Type ហើយសរសេរ Description យ៉ាងតិច 30 តួអក្សរ។
{% endstep %}

{% step %}
### បន្ថែម Technical Context

បន្ថែម Technologies និង Versions, Repository URL, Environment, Severity និង SDLC Phase នៅពេលពាក់ព័ន្ធ។ URL ត្រូវចាប់ផ្តើមដោយ `https://`។
{% endstep %}

{% step %}
### បន្ថែមភស្តុតាង

សម្រាប់ Bug ត្រូវមាន Expected Behavior, Actual Behavior និង Reproduction Step យ៉ាងតិចមួយ។ អ្នកអាចបន្ថែម Error Output, Previous Attempts និង Attachments។
{% endstep %}

{% step %}
### ពិនិត្យ Problem ស្រដៀងគ្នា

ពិនិត្យ Duplicate Suggestions ហើយបើកមើល Item ស្រដៀង មុន Publish។
{% endstep %}

{% step %}
### រៀបចំ និងដាក់ស្នើ

ជ្រើស Tags ពិនិត្យ Readiness Checklist ហើយ Save Draft ឬ Submit for Approval។
{% endstep %}
{% endstepper %}

បើក **Dashboard → My Community** ដើម្បីមើលស្ថានភាព កែ ឬគ្រប់គ្រង Problem តាមសិទ្ធិ និង Status។ Published Problem អាចទទួល Solutions, Votes, Comments និង Views។ Accepted Solution អាចធ្វើឱ្យ Problem ក្លាយជា Resolved។
