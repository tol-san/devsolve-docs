# គ្រប់គ្រង My Community

**My Community** គឺជា Workspace ឯកជនសម្រាប់មាតិកាដែលអ្នកបានសរសេរ។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** អ្នក Sign in  
**ទីតាំង:** **Dashboard → My Community**
{% endhint %}

អ្នកអាចគ្រប់គ្រង Problems, Solutions និង Showcases របស់ខ្លួន រួមទាំង Draft, Pending, Published/Approved, Rejected, Resolved ឬ Closed តាមប្រភេទមាតិកា។

ប្រើ Content Type និង Status Filters ដើម្បីស្វែងរក Item។ បើក Action Menu ដើម្បី View, Edit, Resume ឬ Delete។ Action អាស្រ័យលើ Ownership និង Status។ Solution ដែលមិនអាចរក Parent Problem ឃើញ មិនអាចបើក Edit Route ធម្មតាបានទេ។

{% hint style="warning" %}
ការលុបមាតិកាអាចដកវាចេញពី Workspace និង Public Discovery។ ពិនិត្យ Title ក្នុង Confirmation Dialog មុនបន្ត។
{% endhint %}
