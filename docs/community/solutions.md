# សរសេរ និងគ្រប់គ្រង Solution

Solution គឺជាចម្លើយសម្រាប់ Problem ជាក់លាក់។ វាគួរអាចផ្ទៀងផ្ទាត់ឡើងវិញ និងពន្យល់មូលហេតុដែលវិធីសាស្ត្រនោះដំណើរការ។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** អ្នក Sign in ដែលមិនមែនជា Problem Author  
**ទីតាំង:** បើក Problem → ជ្រើស Answer/Solution Action
{% endhint %}

| Approach | អត្ថន័យ |
| --- | --- |
| Fix | ដោះស្រាយមូលហេតុ |
| Workaround | ជៀសវាងបញ្ហា ដោយមិនលុបមូលហេតុ |
| Explanation | ពន្យល់មូលហេតុ ដោយមិនផ្លាស់ប្តូរ Code |
| Alternative | ផ្តល់ផ្លូវផ្សេង |

1. បញ្ចូល Summary 10–250 តួអក្សរ។
2. សរសេរ Explanation យ៉ាងតិច 30 តួអក្សរ។
3. ជ្រើស Approach Type។
4. បន្ថែម Verification Steps និង Expected Result។
5. កត់ Technologies និង Versions ដែលបាន Test។
6. ពន្យល់ Trade-offs និង Limitations។
7. បន្ថែម Resources និង Attachments; URL ត្រូវជា `https://`។
8. ពិនិត្យ Readiness List ហើយ Submit។

Solution អាចមាន Status **Pending**, **Approved** ឬ **Rejected**។ បើក **My Community** ដើម្បីគ្រប់គ្រង Solution របស់អ្នក។ អ្នកអាចកែបានតែ Solution របស់ខ្លួន។ Accepted Solution អាចធ្វើឱ្យ Problem បង្ហាញថា Solved។
