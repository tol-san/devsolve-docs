## Is DevSolve only for vulnerability Reports?

No. DevSolve includes public Problems, Solutions, and Showcases; security Programs and private Reports; profiles, follows, bookmarks, Hacktivity, Leaderboard, teams, and organization/admin workspaces.

## What should I read first?

- Community author: [Community](../community/README.md)
- Security researcher: [Researcher guide](../researchers/README.md)
- Organization: [Organization guide](../organizations/README.md)
- Administrator: [Administrator guide](../administration/README.md)

## Why is a feature missing from my sidebar?

Sidebar entries depend on account role, active organization, ownership, and explicit permissions. Ask the organization owner to review your membership permissions when a required organization tool is absent.
