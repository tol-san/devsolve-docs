<details>
<summary>What is the difference between a Problem and a vulnerability Report?</summary>

A Problem is public technical Community content after approval. A Vulnerability Report is a private disclosure to an organization under a Program. Sensitive findings belong in Reports.

</details>

<details>
<summary>Why can’t I create a Solution from the new-post screen?</summary>

A Solution must belong to a Problem. Open the Problem and choose its answer action.

</details>

<details>
<summary>Can I answer my own Problem?</summary>

The current Solution creation screen blocks the Problem author from answering their own Problem.

</details>

<details>
<summary>Why is my post not public?</summary>

It may still be a Draft, await approval, or have been rejected. Open **My Community** to see its state and available actions.

</details>

<details>
<summary>What belongs in a Showcase?</summary>

A project, architecture explanation, or technical guide with a clear summary and useful build steps. You can add code, screenshots, diagrams, technologies, and external links.

</details>
