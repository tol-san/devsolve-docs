# Platform security incidents

<a href="/km/administration/security-incidents" class="button secondary">ខ្មែរ</a>

The administrative Security Incidents area helps administrators monitor organization account/security states and inspect incident details.

1. Open **Dashboard → Security Incidents**.
2. Search or filter the available records.
3. Open the detail view and verify organization identity, timestamps, evidence, and current state.
4. Coordinate response through approved internal procedures.
5. Apply only supported, authorized account or incident actions.

The frontend recognizes organization/security states including **Active**, **Suspended**, **Banned**, **Pending**, and **Removed**. These are operational states, not Community moderation statuses or vulnerability Report states.
