# Verification and user management

## Verify organizations

1. Open **Organization Verification**.
2. Filter or search applications.
3. Review legal identity, website, verified domain, owner email, email-verification state, industry, and submission details.
4. Approve or reject using evidence and platform policy.
5. Review prior decisions when history is available.

## Review Programs

Open **Program Review** to inspect submitted Program identity, Scope, exclusions, rules, targets, and reward claims. Approve only when the Program is complete and safe for researchers; reject with an actionable reason.

## Manage users

Open **Users** to search accounts, inspect their status and moderation history, and apply an authorized action. Supported account states include **Active**, **Suspended**, and **Pending**. Record a clear reason and avoid exposing administrative evidence publicly.
