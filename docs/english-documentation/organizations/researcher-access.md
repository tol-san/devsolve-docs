# Manage Researcher Access

<a href="/km/organizations/researcher-access" class="button secondary">ខ្មែរ</a>

Researcher Access controls who outside the organization may report to its Programs.

{% hint style="info" %}
**Required permission:** `MANAGE_RESEARCHERS`  
**Navigation:** **Dashboard → Researcher Access**
{% endhint %}

## Review requests

1. Open the access queue.
2. Review the researcher’s public identity and submitted background.
3. Approve only when the person meets the organization’s access policy.
4. Reject with an accurate decision when access should not be granted.
5. Review active researchers periodically and revoke access when necessary.

Organizations can also invite a researcher directly using the supported identifier and an optional note. This reporting permission is separate from inviting someone as an internal team member.

{% hint style="warning" %}
One access decision applies across the organization’s Programs, but it does not override each Program’s Scope, Rules, status, or dates.
{% endhint %}
