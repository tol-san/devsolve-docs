## Organization states

The interface recognizes states such as **Pending**, **Active**, **Rejected**, and **Suspended**. A pending or rejected state can limit actions until the organization completes the requested verification work.

## Edit the profile

1. Open organization settings and choose the edit action.
2. Review organization name, domain, website, industry, company size, country/region, and description.
3. Upload or link a logo and cover banner using supported formats.
4. Save and resolve any validation error.
5. Return to the organization view and confirm the result.

Verification is reviewed by a platform administrator. When a resubmission action is available, correct the organization information first and then resubmit.
