# Create and manage Programs

A Program tells researchers what they may test, how to report, and what response or reward policy applies.

{% hint style="info" %}
**Create:** `CREATE_PROGRAM`  
**View:** `VIEW_PROGRAMS`  
Editing, lifecycle, and deletion require their corresponding permissions.
{% endhint %}

## Create a Program

1. Open **Dashboard → Create Program**.
2. Enter the Program identity, handle, description, and relevant dates.
3. Add target assets and identify what is in scope.
4. Define exclusions and testing rules clearly.
5. Configure severity/reward information only when the organization intends to honor it.
6. Review the Program and save a Draft or submit it for review.

## Manage lifecycle

Open **Program Management** to search and filter Programs. Depending on status and permission, you can inspect, edit, submit, publish, pause, resume, close, or delete a Program.

{% hint style="warning" %}
Changing Scope or Rules affects researcher authorization. Use clear effective dates and communicate material changes through supported Program updates.
{% endhint %}

Platform administrators review submitted Programs. A rejected Program should be corrected using the recorded reason before resubmission.
