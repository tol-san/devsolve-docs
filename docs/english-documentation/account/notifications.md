# Notifications

<a href="https://docs.devsolve.app/km/account/notifications" class="button secondary">🇰🇭 ខ្មែរ</a>

Notifications keep supported account, Community, access, team, Program, and Report events in one place.

## Use the notification center

1. Select the bell in the public or Dashboard header.
2. Review the unread count and newest items.
3. Open an item to follow its supported destination.
4. Mark one item as read or use **Mark all as read**.
5. Refresh the list when an expected event is missing.

Open **Dashboard → Notifications** for the full page. Notification preferences are saved through the available preferences controls. In-app and email delivery depend on the event and configured backend channels; do not assume every event uses both.
