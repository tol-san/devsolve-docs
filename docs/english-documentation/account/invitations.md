# Accept organization invitations

Any signed-in DevSolve user can be invited to an organization team. Invitations addressed to your account appear under **Dashboard → Invitations**, regardless of whether you are a Researcher, an organization Owner, or already belong to another team.

## Review an invitation

1. Open **Dashboard → Invitations**.
2. Select **Refresh** if you expect a new invitation that is not visible yet.
3. Confirm the organization name, inviter, assigned role, access summary, sent date, and expiry.
4. Select **Accept invitation**.
5. After confirmation, select **Open your team**.

The list shows only invitations that are still waiting and usable. Accepted or expired invitations leave the list automatically.

## Accept from an email link

An invitation email can link directly to `/invitations/[token]`.

- If you are signed out, select **Sign in**. DevSolve returns you to the invitation afterward.
- Sign in with the exact email address to which the invitation was sent.
- DevSolve applies the role and permissions selected by the organization.
- Invitations expire after seven days.

The organization may also share the generated invitation link directly if the email does not arrive. Treat the link as private even though it only works for the invited account.

## Troubleshoot acceptance

| Message or state | What to do |
| --- | --- |
| Session ended | Sign in again and return to **Invitations**. |
| Sent to a different account | Sign out, then sign in using the invited email address. |
| Link is invalid or withdrawn | Ask the organization Owner for a new invitation. |
| Already used | Open **My Team**; the membership may already be active. |
| Expired | Ask the Owner to create a new invitation. |
| Service error | Select **Try again** or refresh the list. |

Accepting an invitation adds an organization workspace to your existing account. It does not remove your Researcher features or memberships in other organizations.
