# Profile and settings

Your public profile helps other users understand your identity and contributions.

## Edit your profile

Open **Dashboard → Profile** and edit the available sections:

- Display/personal details and location
- Contact details when supported
- Biography with Markdown preview
- GitHub, X, LinkedIn, and website links
- Avatar and cover image

Use the profile-completion indicator as guidance, preview the result, and save. Public profiles can show Overview, Hacktivity, Community, Hall of Thanks, badges, severity statistics, and follow relationships according to available data.

## Settings

Open the account settings action from the profile/sidebar. Only controls connected to the current backend should be treated as effective. Authentication remains managed through the configured identity provider; do not assume the settings panel can change an external-provider password or list every active session.
