# Manage My Community

<a href="https://docs.devsolve.app/km/community/my-community" class="button secondary">🇰🇭 ខ្មែរ</a>

**My Community** is the private workspace for content you authored.

{% hint style="info" %}
**Available to:** Signed-in users  
**Navigation:** **Dashboard → My Community**
{% endhint %}

## What you can manage

- Problems, including Drafts and items awaiting approval
- Solutions attached to Problems
- Showcases and revision requests
- Published, approved, rejected, resolved, or closed content as supported by each type

Use content-type and status filters to find an item. Open the available action menu to view, edit, resume, or delete it. Actions vary by ownership and status; an answer that is not attached to a retrievable Problem cannot open its normal edit route.

{% hint style="warning" %}
Deleting content can remove it from your workspace and public discovery. Read the confirmation dialog and verify the title before continuing.
{% endhint %}

## Why an item is not public

Drafts were not submitted. Pending items await moderation. Rejected items require correction or are not eligible for publication. Use [Community review and statuses](moderation-and-statuses.md) to interpret each state.
