# Create and manage Showcases

<a href="https://docs.devsolve.app/km/community/showcases" class="button secondary">ខ្មែរ</a>

A Showcase is a structured public presentation of a project, architecture, or technical build guide.

{% hint style="info" %}
**Available to:** Signed-in users  
**Navigation:** **Community → Start a discussion → Showcase Project**
{% endhint %}

## Build a Showcase

{% stepper %}
{% step %}
### Introduce the project

Add a cover image, title, summary, category, and the technology stack. The summary also helps readers understand the item in the Showcase listing.
{% endstep %}

{% step %}
### Add project links

Add supported `https://` links such as the source repository, live demonstration, or walkthrough video.
{% endstep %}

{% step %}
### Create build steps

Give each step a title and explanation. Add screenshots, code snippets, or a diagram where they help the reader reproduce or understand the work. Steps can be duplicated, reordered, or removed in the authoring interface.
{% endstep %}

{% step %}
### Add resources

Add labeled supporting links such as design files, documentation, articles, or repositories.
{% endstep %}

{% step %}
### Review and submit

Check the preview and submit the Showcase for moderation. It is not public merely because the form was completed.
{% endstep %}
{% endstepper %}

## Diagram builder

The built-in diagram editor supports reusable templates and editable nodes/connectors for technical diagrams such as data models, class structures, flows, and architecture explanations. Fit the diagram to the viewport, use clear labels, and verify it remains readable before saving.

## Review and revision

A Showcase moves through **Pending**, **Approved**, or **Changes requested/Rejected** review states. If changes are requested, open it from **My Community** or its Dashboard edit route, address the reason, and submit the revision. Approved Showcases appear in the public Showcase listing.
