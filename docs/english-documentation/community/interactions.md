# Votes, comments, bookmarks, and follows

DevSolve lets signed-in users organize useful content and participate in public technical discussion.

## Vote

Use the vote control on supported Problems and Solutions to signal usefulness. Vote based on technical quality, not personal relationships. The displayed total updates from the platform’s vote summary.

## Comment

Use comments to request clarification, share a focused improvement, or discuss evidence. Replies form threads where supported. Authors can edit or remove their own comment according to the available actions.

## Bookmark

Select the bookmark control on supported content, then open **Dashboard → Bookmarks** to search or remove saved items. Bookmarking is private organization; it does not publish or approve the content.

## Follow

Open a public profile and select **Follow**. Use the profile’s **Followers** and **Following** pages to inspect the visible network. Following is separate from organization membership and Researcher Access.

## Report content

Use the report/flag action when content violates Community rules. Give an accurate reason. Platform administrators review Content Reports and may resolve or dismiss them.
