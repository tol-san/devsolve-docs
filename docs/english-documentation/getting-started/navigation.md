# Navigate DevSolve

<a href="https://docs.devsolve.app/km/getting-started/navigation" class="button secondary">🇰🇭 ខ្មែរ</a>

DevSolve has a public navigation bar and a role-aware Dashboard sidebar.

## Public navigation

| Item | What it opens |
| --- | --- |
| **Home** | Product introduction and entry points |
| **Programs** | Public security Program marketplace |
| **Community** | Menu for Community, Hacktivity, Problems, and Showcases |
| **Leaderboard** | Researcher reputation rankings |
| **Docs** | This user guide |
| **About** | DevSolve mission, architecture, and team information for guests |

The header also provides search, language, theme, notifications when signed in, and the account menu.

## Dashboard sidebar

All signed-in users see common areas such as **Dashboard**, **Programs**, **Community**, **My Community**, **Leaderboard**, and **Invitations**. Other entries depend on role, organization membership, and permissions.

### Researcher entries

**Reports**, **Rewards**, **Bookmarks**, **Saved Drafts**, and **My Access**.

### Organization entries

Possible entries include **Program Management**, **Create Program**, **Report Management**, **Security Incidents**, **Team Management**, and **Researcher Access**. A member sees only what their permissions allow. Team and organization-profile management are owner-only where the upstream service requires ownership.

### Administrator entries

**Organization Verification**, **Program Review**, **Users**, **Content Management**, **AI Auto-Approval**, **Security Incidents**, **Categories**, **Tags**, and **Weaknesses**.

## Switch workspaces

If you belong to multiple organizations, use the organization switcher in the sidebar. The selected workspace changes which organization’s Programs, Reports, analytics, and access lists are shown.
