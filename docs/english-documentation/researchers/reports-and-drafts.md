# Reports and saved drafts

<a href="/km/researchers/reports-and-drafts" class="button secondary">ខ្មែរ</a>

Use **Reports** to track submitted findings and **Saved Drafts** to resume incomplete submissions.

## Find a Report

1. Open **Dashboard → Reports**.
2. Search by Report, Program, or other available text.
3. Filter by status, severity, or Program.
4. Open a Report card to see its full detail.

The detail page can include target and classification data, description, impact, reproduction steps, proof of concept, remediation, references, attachments, comments, activity updates, rewards, and retest history. Empty fields are omitted rather than invented.

## Work with Drafts

The report form saves server-backed Drafts where supported and can offer to resume an existing Program draft. Open **Dashboard → Saved Drafts**, choose the relevant type, search for the Draft, and select the resume action.

Delete a Draft only when you are certain it is no longer needed.

{% hint style="info" %}
Community Problems can also have Draft status. The Saved Drafts view may contain more than one supported content type; always check the type and title before resuming or deleting.
{% endhint %}
