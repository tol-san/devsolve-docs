# Request Researcher Access

<a href="https://docs.devsolve.app/km/researchers/researcher-access" class="button secondary">🇰🇭 ខ្មែរ</a>

An organization can require approval before you report to any of its Programs. This is organization-level access, not a separate decision for each Program.

{% hint style="info" %}
**Available to:** Individual/researcher accounts  
**Navigation:** Program details or **Dashboard → My Access**
{% endhint %}

## Request access

1. Open a Program owned by the organization.
2. If reporting is restricted, choose the request-access action.
3. Describe your background, the kinds of issues you test, and useful experience.
4. Submit the request.
5. Open **My Access** to track the organization’s decision.

## Access states

| State | What to do |
| --- | --- |
| Pending | Wait for the organization to review the request |
| Approved | Open one of the organization’s Programs, confirm Scope and Rules, and start the report form |
| Rejected or revoked | Do not submit or continue testing; contact the organization only through supported channels if clarification is needed |

Open an organization in **My Access** to see its access details and Programs. Approval can be changed by the organization, so check it before starting new testing.
