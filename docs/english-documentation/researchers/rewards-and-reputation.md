# Rewards, reputation, and recognition

<a href="https://docs.devsolve.app/km/researchers/rewards-and-reputation" class="button secondary">ខ្មែរ</a>

DevSolve distinguishes organization-funded bounty records, platform reputation, and Hall of Thanks recognition.

| Item | Meaning |
| --- | --- |
| Bounty reward | Money an organization records for an eligible Report |
| Reputation points | Platform score awarded for supported valid-finding outcomes |
| Recognition | A one-time thank-you from an organization for an eligible resolved Report |
| Hall of Thanks | Public presentation of supported recognition records |

Reputation drives the Leaderboard; payout size does not. A Report’s stored reputation award is shown as recorded rather than recalculated from a later severity change.

{% hint style="warning" %}
The current **Dashboard → Rewards** page uses demonstration data. Its totals, payout statuses, export button, and sample transactions must not be treated as real balances or payment commitments.
{% endhint %}

DevSolve Docs does not promise withdrawal methods, minimum thresholds, KYC rules, or payment times because those workflows are not implemented in the inspected frontend. Use the individual Report and Program policy as the reliable source for recorded rewards.
