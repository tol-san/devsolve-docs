# Search, Hacktivity, and Leaderboard

Use these public areas to find content and understand visible platform activity.

## Global search

Use the search control in the public header or Dashboard header. Enter a meaningful title, technology, Program, organization, or username. Open **Search** for the full result view and select a result type to narrow the list when available.

Search results depend on indexed, visible content. Private Reports and unpublished Community content are not public search results.

## Hacktivity

Hacktivity presents publishable security activity. Use its filters and pagination to explore recent disclosures and recognition. The feed shows only information the platform has made visible; it is not a view into private Report content.

## Leaderboard

The Leaderboard ranks researchers by reputation from valid findings and organization recognition, not by payout size. Use the available time or ranking controls and open a researcher to inspect their public profile.

{% hint style="info" %}
Rankings can change when new reputation events are recorded. A missing rank does not necessarily mean an account is inactive.
{% endhint %}
