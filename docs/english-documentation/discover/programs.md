# Browse security Programs

A Program defines an organization’s authorized targets, rules, and possible rewards for private vulnerability reporting.

{% hint style="info" %}
**Available to:** Everyone can browse; an approved researcher is required to submit  
**Navigation:** **Programs**
{% endhint %}

## Find a Program

1. Open **Programs**.
2. Search by Program or organization name.
3. Use the available filters, such as asset type, maximum severity, industry, or reward range.
4. Choose a sorting option and open a Program card.

## Read Program details

Review every tab before testing:

- **Overview** — Program description and key information
- **Scope** — allowed and excluded assets
- **Rules** — testing and disclosure requirements
- **Bounty Matrix** — reward ranges when the Program offers bounties
- **Hall of Thanks** — researchers recognized by the Program

{% hint style="danger" %}
Never begin testing based only on a Program card. Confirm that the exact asset and activity are allowed by the current Scope and Rules.
{% endhint %}

## Submit eligibility

Reporting can be gated by organization-level **Researcher Access**. If the Program’s report action says you are not approved, request access and track it under **Dashboard → My Access**.

The retired `/program` route is not the marketplace. Use `/programs`.
