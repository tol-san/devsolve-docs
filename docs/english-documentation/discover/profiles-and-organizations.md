# Profiles and organizations

<a href="https://docs.devsolve.app/km/discover/profiles-and-organizations" class="button secondary">ខ្មែរ</a>

Public profiles show identity and contribution information that a user or organization has chosen or is allowed to expose.

## Researcher profiles

A profile can include:

- Overview statistics and severity breakdown
- Biography, location, website, and social links
- Badges
- Hacktivity
- Community Problems, Solutions, and Showcases
- Hall of Thanks recognitions
- Followers and following

Select **Follow** to receive the supported social relationship when signed in. Use the follower and following pages to search a profile’s network.

## Organization profiles

An organization view can show its identity, verification state, Programs, members, and other public information. Organization owners edit private profile settings from the Dashboard rather than from the public page.

{% hint style="warning" %}
Verification means the platform approved the organization record. It does not replace your responsibility to read each Program’s Scope and Rules.
{% endhint %}
