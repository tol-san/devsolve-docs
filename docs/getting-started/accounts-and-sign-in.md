# គណនី ការចុះឈ្មោះ និងការចូលប្រើ

<a href="https://docs.devsolve.app/en/getting-started/accounts-and-sign-in" class="button secondary">🇬🇧 English</a>

ជ្រើសគណនី Individual ដើម្បីចូលរួមដោយផ្ទាល់ ឬគណនី Organization ដើម្បីដំណើរការ Security Programs។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** អ្នកទស្សនា  
**ទីតាំង:** **Get Started** ឬ **Log in**
{% endhint %}

## ចុះឈ្មោះគណនីផ្ទាល់ខ្លួន

1. ជ្រើស **Get Started** ហើយជ្រើស Individual/Researcher។
2. បំពេញព័ត៌មានផ្ទាល់ខ្លួន ទំនាក់ទំនង និងគណនីដែល Form ស្នើសុំ។
3. ពិនិត្យលក្ខខណ្ឌដែលបង្ហាញលើទំព័រ។
4. ដាក់ស្នើ ហើយកែ Validation Error តាម Field។
5. បន្តទៅ DevSolve ក្រោយការចុះឈ្មោះជោគជ័យ។

## ចុះឈ្មោះអង្គការ

1. ជ្រើស **Get Started** ហើយជ្រើស Company/Organization។
2. បំពេញ Form អង្គការទាំងពីរជំហាន។
3. ផ្តល់ព័ត៌មានអង្គការ និងទំនាក់ទំនងម្ចាស់ឱ្យត្រឹមត្រូវ។
4. ដាក់ស្នើការចុះឈ្មោះ។
5. បើក Organization Workspace និងបំពេញ Verification មុនរំពឹងថា Program នឹងផ្សព្វផ្សាយជាសាធារណៈ។

## ចូលប្រើ

ទំព័រ Sign in បញ្ជូនការផ្ទៀងផ្ទាត់តាម Keycloak។ អ្នកអាចប្រើ Keycloak Form ឬជ្រើស **Google** ឬ **GitHub** នៅពេល Provider ទាំងនោះអាចប្រើបាន។

1. បើក **Log in**។
2. ជ្រើស Google, GitHub ឬ Keycloak។
3. បំពេញការផ្ទៀងផ្ទាត់នៅទំព័រ Identity Provider។
4. អ្នកនឹងត្រឡប់ទៅ Dashboard ឬទំព័រដែលបានស្នើឱ្យ Sign in។
