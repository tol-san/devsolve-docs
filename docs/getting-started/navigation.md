# របៀបរុករក DevSolve

<a href="/en/getting-started/navigation" class="button secondary">English</a>

DevSolve មាន Public Navigation Bar និង Dashboard Sidebar ដែលប្រែប្រួលតាមតួនាទី។

## Public navigation

| Item | ទំព័រដែលបើក |
| --- | --- |
| **Home** | សេចក្តីណែនាំ និងផ្លូវចាប់ផ្តើម |
| **Programs** | Marketplace សម្រាប់ Security Programs |
| **Community** | Menu សម្រាប់ Community, Hacktivity, Problems និង Showcases |
| **Leaderboard** | ចំណាត់ថ្នាក់កេរ្តិ៍ឈ្មោះ Researcher |
| **Docs** | មគ្គុទ្ទេសក៍នេះ |
| **About** | បេសកកម្ម Architecture និងព័ត៌មានក្រុម DevSolve សម្រាប់ Guest |

Header ក៏មាន Search, Language, Theme, Notifications នៅពេល Sign in និង Account Menu។

## Dashboard sidebar

អ្នក Sign in ទាំងអស់ឃើញ **Dashboard**, **Programs**, **Community**, **My Community**, **Leaderboard** និង **Invitations**។ Item ផ្សេងទៀតអាស្រ័យលើ Role, Organization Membership និង Permissions។

- Researcher: **Reports**, **Rewards**, **Bookmarks**, **Saved Drafts**, **My Access**
- Organization: **Program Management**, **Create Program**, **Report Management**, **Security Incidents**, **Team Management**, **Researcher Access** តាមសិទ្ធិ
- Administrator: **Organization Verification**, **Program Review**, **Users**, **Content Management**, **AI Auto-Approval**, **Security Incidents**, **Categories**, **Tags**, **Weaknesses**

បើអ្នកជាសមាជិកអង្គការច្រើន ប្រើ Organization Switcher នៅ Sidebar មុនគ្រប់គ្រង Programs, Reports ឬ Analytics។
