# ការផ្តល់រង្វាន់ដល់ Researcher

ការផ្តល់រង្វាន់ឆាប់រហ័ស និងសមរម្យ គឺជាកត្តាសំខាន់បំផុតដែលជំរុញឱ្យអ្នកស្រាវជ្រាវបន្តជួយការពារប្រព័ន្ធរបស់អ្នកយូរអង្វែង។

***

## 💳 របៀបអនុម័ត និងផ្តល់ Bounty

1. នៅក្នុងទំព័រ Report ដែលមានស្ថានភាព `Triaged` ឬ `Resolved` សូមចុចលើប៊ូតុង **"Award Bounty"**។
2. ប្រព័ន្ធនឹងបង្ហាញផ្ទាំងជ្រើសរើសទឹកប្រាក់៖
   * **Bounty Amount ($):** បញ្ចូលចំនួនទឹកប្រាក់ផ្អែកតាម Reward Grid ដែលបានកំណត់។
   * **Bonus Amount ($) (ស្រេចចិត្ត):** ប្រាក់លើកទឹកចិត្តបន្ថែមសម្រាប់របាយការណ៍ពិសេស។
   * **Message to Researcher:** សារថ្លែងអំណរគុណជាលាយលក្ខណ៍អក្សរ។
3. ចុច **"Confirm & Disburse"**៖
   * ទឹកប្រាក់នឹងត្រូវកាត់ចេញពីគណនី Deposit របស់ក្រុមហ៊ុន ហើយបញ្ចូលទៅក្នុង Wallet របស់ Researcher ភ្លាមៗ។
   * ពិន្ទុ Reputation នឹងត្រូវបានបន្ថែមដោយស្វ័យប្រវត្តិតាមកម្រិត Severity នៃ Report។

***

## ⏱️ រយៈពេលកំណត់ក្នុងការផ្តល់រង្វាន់ (SLA Standards)

ដើម្បីរក្សាភាពវិជ្ជមាននៃកម្មវិធី DevSolve លើកទឹកចិត្តឱ្យក្រុមហ៊ុនគោរពតាម SLA ដូចខាងក្រោម៖

* **First Response SLA:** ឆ្លើយតបដំបូងក្នុងរយៈពេល **៤៨ ម៉ោង** នៃថ្ងៃធ្វើការ។
* **Triage SLA:** បញ្ជាក់ភាពត្រឹមត្រូវក្នុងរយៈពេល **៥ ថ្ងៃនៃថ្ងៃធ្វើការ**។
* **Bounty SLA:** អនុម័តប្រាក់រង្វាន់ក្នុងរយៈពេល **៧ ទៅ ១៤ ថ្ងៃ** បន្ទាប់ពី Triaged (មិនចាំបាច់រង់ចាំដល់ Fix រួចរាល់ទើបឱ្យលុយនោះទេ ប្រសិនបើ Bug ត្រូវបានបញ្ជាក់ថាត្រឹមត្រូវ)។
