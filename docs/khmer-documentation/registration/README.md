# ៣. សម្រាប់ក្រុមហ៊ុន (Organizations)

ដើម្បីធានានូវបរិយាកាសដែលអាចទុកចិត្តបានសម្រាប់ Security Researchers ក្រុមហ៊ុនទាំងអស់ត្រូវតែបំពេញលក្ខខណ្ឌចុះឈ្មោះ និងឆ្លងកាត់ដំណើរការ **Company Verification** មុនពេលអាច Publish កម្មវិធី Bug Bounty ជាសាធារណៈបាន។

***

## 🏢 ១. ដំណើរការចុះឈ្មោះក្រុមហ៊ុន (Company Registration)

1. ចូលទៅកាន់ `/register/company` ហើយបំពេញព័ត៌មានលម្អិតរបស់ក្រុមហ៊ុន៖
   * ឈ្មោះផ្លូវការរបស់ក្រុមហ៊ុន (Legal Business Name)
   * អាសយដ្ឋានគេហទំព័រ (Official Website URL)
   * អ៊ីមែលការងារផ្លូវការ (Business Work Email)
   * លេខទូរស័ព្ទ និងអាសយដ្ឋានការិយាល័យ
2. បញ្ជាក់ការចុះឈ្មោះតាមរយៈតំណភ្ជាប់ដែលបានផ្ញើទៅកាន់អ៊ីមែលការងារ។
3. ចូលទៅកាន់ Dashboard របស់ក្រុមហ៊ុន។

***

## 🛡️ ២. ដំណើរការស្នើសុំ Company Verification Badge

ការទទួលបាន Badge បញ្ជាក់ក្រុមហ៊ុន (Verified Badge) នឹងបង្កើនទំនុកចិត្តយ៉ាងខ្លាំងពីសំណាក់ Hackers ជាន់ខ្ពស់៖

1. នៅក្នុង Company Dashboard ចុចលើ **"Request Company Verification"**។
2. ភ្ជាប់ឯកសារផ្លូវការរួមមាន៖
   * លិខិតបញ្ជាក់ការចុះបញ្ជីពាណិជ្ជកម្ម (Certificate of Incorporation / Business Registration)
   * ភស្តុតាងនៃការកាន់កាប់ Domain (ឧ. DNS TXT record ឬ meta-tag ផ្ទៀងផ្ទាត់)
   * ព័ត៌មានអត្តសញ្ញាណរបស់អ្នកតំណាងផ្នែកច្បាប់ ឬ Security Lead
3. ក្រុមការងារ Admin របស់ DevSolve នឹងពិនិត្យឯកសារក្នុងរយៈពេល **២៤ ទៅ ៤៨ ម៉ោង**។
4. នៅពេលត្រូវបានអនុម័ត ក្រុមហ៊ុនរបស់អ្នកនឹងទទួលបានសញ្ញា **Verified Organization Badge** និងអាចបើកដំណើរការ Bug Bounty Programs ភ្លាមៗ។
