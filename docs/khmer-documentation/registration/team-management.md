# ការគ្រប់គ្រងសមាជិកក្រុម

ក្រុមហ៊ុនភាគច្រើនមានសមាជិកច្រើននាក់ដែលត្រូវចូលរួមក្នុងការពិនិត្យកូដ និងដោះស្រាយបញ្ហាសុវត្ថិភាព។ DevSolve ផ្តល់នូវប្រព័ន្ធគ្រប់គ្រងសមាជិកក្រុម និងការបែងចែកសិទ្ធិយ៉ាងលម្អិត។

***

## 👥 របៀប Invite សមាជិកក្រុមថ្មី

1. ចូលទៅកាន់ **Team Management** (`/dashboard/team-management`)។
2. ចុចលើប៊ូតុង **"Invite Member"**។
3. បញ្ចូល **Email Address** របស់សមាជិក និងជ្រើសរើស **Role** ដែលត្រូវផ្តល់ឱ្យ។
4. ចុច **Send Invitation**។ សមាជិកនោះនឹងទទួលបានអ៊ីមែលដែលមានតំណភ្ជាប់ដើម្បីចូលរួមជាមួយស្ថាប័នរបស់អ្នក។

***

## 🔑 តួនាទី និងកម្រិតសិទ្ធិ (Roles & Permissions)

| Role                           | សិទ្ធិ និងភារកិច្ច                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Owner / Organization Admin** | មានសិទ្ធិពេញលេញលើគណនីក្រុមហ៊ុន៖ បង្កើត/កែប្រែ Program, គ្រប់គ្រង Billing & Deposits, អនុម័ត Bounty Payout, Invite/Remove សមាជិក។           |
| **Security Lead / Triager**    | អាចបើកមើល Reports, សរសេរ Comment ឆ្លើយឆ្លងជាមួយ Researcher, ផ្លាស់ប្តូរ Status (Triaged, Resolved, Duplicate), កែសម្រួល Severity។          |
| **Developer / Engineer**       | អាចបើកមើលព័ត៌មានលម្អិតបច្ចេកទេស និង PoC ក្នុង Reports ដើម្បីធ្វើការ Patch កូដ ប៉ុន្តែមិនអាចផ្លាស់ប្តូរ Status ធំៗ ឬបើកប្រាក់រង្វាន់បានឡើយ។ |
| **Billing Specialist**         | អាចមើលឃើញតែផ្ទាំងគ្រប់គ្រងហិរញ្ញវត្ថុ ការបញ្ចូលទឹកប្រាក់ Deposit និង Invoices ពន្ធប៉ុណ្ណោះ។                                                |
