# ស្នើសុំ Researcher Access

<a href="/en/researchers/researcher-access" class="button secondary">English</a>

អង្គការអាចទាមទារការអនុម័ត មុនអ្នកអាចដាក់ Report ទៅ Programs របស់វា។ នេះជាសិទ្ធិកម្រិត Organization មិនមែនសិទ្ធិដាច់ដោយឡែកសម្រាប់ Program នីមួយៗទេ។

{% hint style="info" %}
**អ្នកអាចប្រើបាន:** Individual/Researcher Account  
**ទីតាំង:** Program Details ឬ **Dashboard → My Access**
{% endhint %}

1. បើក Program របស់អង្គការ។
2. បើ Reporting ត្រូវបានកំណត់ ជ្រើស Request Access។
3. ពិពណ៌នា Background, ប្រភេទបញ្ហាដែលអ្នកសាកល្បង និងបទពិសោធន៍។
4. Submit Request។
5. បើក **My Access** ដើម្បីតាមដាន Decision។

| State | អ្វីដែលត្រូវធ្វើ |
| --- | --- |
| Pending | រង់ចាំ Organization Review |
| Approved | បើក Program ពិនិត្យ Scope/Rules ហើយចាប់ផ្តើម Report |
| Rejected ឬ Revoked | បញ្ឈប់ការដាក់ Report និង Testing; ស្នើ Clarification តាម Channel ដែលគាំទ្រ |

Access អាចត្រូវបានផ្លាស់ប្តូរ ដូច្នេះត្រូវពិនិត្យមុនចាប់ផ្តើម Testing ថ្មី។
