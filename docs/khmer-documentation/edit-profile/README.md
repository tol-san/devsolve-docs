# ៤. Profile និងគណនី

Profile របស់អ្នកគឺជាមុខមាត់ឌីជីថល (Digital Resume) នៅលើ DevSolve ដែលបង្ហាញពីសមត្ថភាព ជំនាញ និងកេរ្តិ៍ឈ្មោះរបស់អ្នកក្នុងសហគមន៍។

***

## ✏️ របៀបកែប្រែ Profile

1. ចុចលើរូប Profile របស់អ្នកនៅជ្រុងខាងស្តាំខាងលើ ហើយជ្រើសរើស **"Profile"** (ឬចូលទៅកាន់ `/dashboard/profile/[username]`)។
2. ចុចលើប៊ូតុង **"Edit Profile"** ដើម្បីចូលទៅកាន់ទំព័រ Settings។
3. អ្នកអាចកែសម្រួលព័ត៌មានដូចខាងក្រោម៖
   * **Avatar / Profile Picture:** ផ្ទុកឡើងរូបថតផ្ទាល់ខ្លួន ឬរូប Logo តំណាងរបស់អ្នក។
   * **Display Name & Bio:** សរសេរព័ត៌មានសង្ខេបអំពីខ្លួនអ្នក (ចំណាប់អារម្មណ៍លើ Web/Mobile Security, វិញ្ញាបនបត្រ OSCP, CEH, etc.)។
   * **Skills / Badges:** បញ្ចូលជំនាញបច្ចេកទេស (ឧ. `XSS`, `IDOR`, `Reverse Engineering`, `Cloud Pentesting`)។
   * **Social Profiles:** ភ្ជាប់គណនី GitHub, LinkedIn, Twitter/X, ឬ Personal Blog។
4. ចុច **"Save Changes"** ដើម្បីរក្សាទុកការផ្លាស់ប្តូរ។
