# Follow Users

DevSolve ផ្តល់នូវប្រព័ន្ធបណ្តាញសង្គមសម្រាប់ Security Researchers ដើម្បីងាយស្រួលតាមដានសកម្មភាព និងរៀនសូត្រពីអ្នកជំនាញក្នុងវិស័យនេះ។

***

## 🤝 របៀប Follow អ្នកស្រាវជ្រាវដទៃទៀត

1. ចូលទៅកាន់ Profile របស់អ្នកប្រើប្រាស់ណាដែលអ្នកចាប់អារម្មណ៍ (តាមរយៈ Leaderboard, Hacktivity, ឬ Discussions)។
2. ចុចលើប៊ូតុង **"Follow"**។
3. នៅពេលអ្នក Follow នរណាម្នាក់៖
   * អ្នកនឹងទទួលបានព័ត៌មានថ្មីៗនៅពេលដែលគាត់បង្ហោះ Showcases ឬបើកបង្ហាញ Disclosed Reports។
   * អ្នកអាចមើលបញ្ជី **Followers** (អ្នកដែល Follow អ្នក) និង **Following** (អ្នកដែលអ្នកបាន Follow) នៅក្នុងទំព័រ Profile ផ្ទាល់ខ្លួនរបស់អ្នក។
