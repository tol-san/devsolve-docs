# Settings

ទំព័រ Settings អនុញ្ញាតឱ្យអ្នកគ្រប់គ្រងគណនី សុវត្ថិភាព និងការកំណត់ផ្ទាល់ខ្លួន។

***

## ⚙️ ការកំណត់ទូទៅ (Account Settings)

ចូលទៅកាន់ **Account Settings** តាមរយៈ `/dashboard/profile/settings`៖

* **Personal Info:** កែប្រែឈ្មោះ អ៊ីមែលទំនាក់ទំនង និងតំបន់ពេលវេលា (Timezone)។
* **Notification Preferences:** ជ្រើសរើសប្រភេទ Email Notifications ណាដែលអ្នកចង់ទទួលបាន និងមួយណាដែលចង់បិទ។

***

## 🛡️ ការកំណត់សុវត្ថិភាព (Security Settings)

* **Change Password:** ផ្លាស់ប្តូរលេខសម្ងាត់ថ្មីជាប្រចាំ ដើម្បីធានាសុវត្ថិភាព។
* **Two-Factor Authentication (2FA):** បើកដំណើរការ 2FA តាមរយៈ Google Authenticator ឬ Authy ដើម្បីការពារគណនីពេល Login។
* **Active Sessions Management:** មើលបញ្ជី Devices និង Browsers ដែលកំពុង Login គណនីរបស់អ្នក។ អ្នកអាចចុច **"Revoke Session"** ឬ **"Log out from all devices"** ប្រសិនបើសង្ស័យថាមានការលួចចូលប្រើប្រាស់។
