# ការដោះស្រាយបញ្ហា និងជម្លោះ

DevSolve ផ្តល់យន្តការសម្របសម្រួល និងដោះស្រាយវិវាទ ដើម្បីធានានូវយុត្តិធម៌សម្រាប់គ្រប់ភាគីទាំងអស់។

***

## ❓ ១. ក្រុមហ៊ុនមិនឆ្លើយតប Report ឬឆ្លើយតបយឺតខ្លាំង តើខ្ញុំត្រូវធ្វើដូចម្តេច?

* **ចម្លើយ:** ក្រុមហ៊ុនទាំងអស់ត្រូវគោរពតាម SLA នៃការឆ្លើយតប។ ប្រសិនបើកន្លងផុត **៧ ថ្ងៃនៃថ្ងៃធ្វើការ** ដោយគ្មានការឆ្លើយតប ឬ Update ណាមួយពីក្រុមហ៊ុន៖
  1. សូមចុចលើប៊ូតុង **"Request DevSolve Mediation"** នៅលើទំព័រ Report របស់អ្នក។
  2. ក្រុមការងារ Support របស់ DevSolve នឹងទាក់ទងផ្ទាល់ទៅកាន់ Security Lead របស់ក្រុមហ៊ុននោះ ដើម្បីពន្លឿនដំណើរការ Triage។

***

## ❓ ២. ខ្ញុំមិនយល់ស្របនឹងការបន្ថយ Severity ឬការ Reject Report តើខ្ញុំអាចតវ៉ាបានទេ?

* **ចម្លើយ:** បាន! ប្រសិនបើក្រុមហ៊ុនបដិសេធ Report ឬបន្ថយ Severity ពី Critical មក Low ដោយគ្មានហេតុផលបច្ចេកទេសសមរម្យ៖
  1. ដំបូង សូមសរសេរពន្យល់បច្ចេកទេសបន្ថែមក្នុង Comment ជាមួយ PoC ដែលបង្ហាញពីផលប៉ះពាល់ជាក់ស្តែង (Real-world Attack Scenario)។
  2. ប្រសិនបើនៅតែមិនចុះសម្រុងគ្នា សូមស្នើសុំ **"Mediation Review"** ពី DevSolve Admin។
  3. ក្រុមវិស្វករសុវត្ថិភាពឯករាជ្យរបស់ DevSolve នឹងធ្វើការវាយតម្លៃឡើងវិញ និងសម្រេចសេចក្តីដោយយុត្តិធម៌។

***

## ❓ ៣. ក្រុមហ៊ុនបានជួសជុល (Patch) Bug នោះស្ងាត់ៗ ដោយមិនបានបើក Bounty ឱ្យខ្ញុំ តើត្រូវដោះស្រាយយ៉ាងណា?

* **ចម្លើយ:** DevSolve មានប្រព័ន្ធតាមដានកាលបរិច្ឆេទយ៉ាងតឹងរ៉ឹង។ ប្រសិនបើអ្នកអាចបញ្ជាក់ថា Bug ត្រូវបានជួសជុលបន្ទាប់ពីកាលបរិច្ឆេទដែលអ្នកបាន Submit Report សូមស្នើសុំ Mediation ជាបន្ទាន់។ DevSolve នឹងទាមទារការបកស្រាយ និងអនុវត្តវិធានការដកប្រាក់រង្វាន់ពីក្រុមហ៊ុនជូនអ្នក។
