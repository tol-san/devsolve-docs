# បង្កើត និងគ្រប់គ្រង Program

<a href="https://docs.devsolve.app/en/organizations/programs" class="button secondary">English</a>

Program ប្រាប់ Researcher អំពីអ្វីដែលអាច Test, របៀប Report និង Response/Reward Policy។

{% hint style="info" %}
**Create:** `CREATE_PROGRAM`  
**View:** `VIEW_PROGRAMS`  
ការកែ Lifecycle និង Delete ត្រូវការសិទ្ធិដែលត្រូវគ្នា។
{% endhint %}

1. បើក **Dashboard → Create Program**។
2. បញ្ចូល Identity, Handle, Description និង Dates។
3. បន្ថែម Target Assets និង In-Scope Definition។
4. កំណត់ Exclusions និង Testing Rules ច្បាស់លាស់។
5. កំណត់ Severity/Reward តែនៅពេលអង្គការអាចគោរពតាម។
6. Review ហើយ Save Draft ឬ Submit for Review។

បើក **Program Management** ដើម្បី Search, Filter, View, Edit, Submit, Publish, Pause, Resume, Close ឬ Delete តាម Status និង Permission។

{% hint style="warning" %}
ការកែ Scope ឬ Rules ប៉ះពាល់ការអនុញ្ញាត Testing។ បញ្ជាក់ Effective Date និងផ្សព្វផ្សាយ Material Change តាម Program Update ដែលគាំទ្រ។
{% endhint %}
