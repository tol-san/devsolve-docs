# ត្រួតពិនិត្យ និងគ្រប់គ្រង Report

<a href="/en/organizations/report-management" class="button secondary">English</a>

Private Report Workspace ជួយសមាជិកដែលមានសិទ្ធិពិនិត្យ Scope, Evidence, Severity, Remediation និង Final Outcome។

{% hint style="info" %}
**View:** `VIEW_REPORTS`  
**Triage decision:** `TRIAGE_REPORTS`  
Action ផ្សេងអាចត្រូវការ `MANAGE_DISCLOSURE`, `AWARD_REWARDS` ឬ `MANAGE_PROGRAM_STATE`។
{% endhint %}

1. បើក **Report Management** ឬ **Review Queue**។
2. រៀបចំ **Pending Intake**, **Under Review**, **Approval Ready**។
3. បញ្ជាក់ Organization និង Program។
4. ផ្ទៀងផ្ទាត់ Target ទល់នឹង Scope និងពិនិត្យ Evidence ដោយសុវត្ថិភាព។
5. Review Weakness, CWE, Severity, CVSS, Impact និង Reproduction Steps។
6. ស្នើ Clarification នៅពេល Evidence មិនគ្រប់។
7. ប្រើ **Severity Review** ដើម្បីបញ្ជាក់ Severity និង Final Decision។

Reject បិទ Report ដោយមិន Accepted។ Valid Finding កត់ Approved State និង Severity។ Resolve បន្ទាប់ពី Organization បានដោះស្រាយតាម Process។ អ្នកមានសិទ្ធិអាច Request Retest, កត់ Reward/Recognition និងប្រើ Export Screen។ ត្រូវផ្ទៀងផ្ទាត់ Export ក្នុង Deployment មុនធានាថាអាចប្រើបាន។
