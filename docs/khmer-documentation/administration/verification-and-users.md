# ការផ្ទៀងផ្ទាត់ និងគ្រប់គ្រងអ្នកប្រើ

<a href="/en/administration/verification-and-users" class="button secondary">English</a>

## Verify Organizations

1. បើក **Organization Verification**។
2. Filter ឬ Search Applications។
3. Review Legal Identity, Website, Verified Domain, Owner Email, Email Verification, Industry និង Submission Details។
4. Approve ឬ Reject តាម Evidence និង Platform Policy។
5. ពិនិត្យ Review History នៅពេលមាន។

## Review Programs

បើក **Program Review** ហើយពិនិត្យ Identity, Scope, Exclusions, Rules, Targets និង Reward Claims។ Approve តែនៅពេល Program ពេញលេញ និងមានសុវត្ថិភាព; Reject ជាមួយ Actionable Reason។

## Manage Users

បើក **Users** ដើម្បី Search Account, ពិនិត្យ Status និង Moderation History ហើយ Apply Authorized Action។ State ដែលគាំទ្ររួមមាន **Active**, **Suspended**, **Pending**។
