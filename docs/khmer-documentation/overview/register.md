# របៀបបង្កើតគណនី

ដើម្បីចាប់ផ្តើមប្រើប្រាស់ DevSolve អ្នកត្រូវបង្កើតគណនីស្របតាមតម្រូវការរបស់អ្នក ដោយអនុវត្តតាមជំហានងាយៗដូចខាងក្រោម៖

***

## 🧑‍💻 ជំហានចុះឈ្មោះសម្រាប់ Security Researcher / Developer

1. ចូលទៅកាន់គេហទំព័រ DevSolve ហើយចុចលើប៊ូតុង **Sign Up** ឬចូលទៅកាន់ទំព័រ [Account Type Selection](https://devsolve-frontend.vercel.app/account-type)។
2. ជ្រើសរើសយកជម្រើស **"Individual / Security Researcher"**។
3. បំពេញព័ត៌មានចាំបាច់៖
   * **Username:** ឈ្មោះសម្គាល់ក្នុងប្រព័ន្ធ (នឹងបង្ហាញជាសាធារណៈលើ Leaderboard)
   * **Full Name:** ឈ្មោះពេញរបស់អ្នក
   * **Email Address:** អ៊ីមែលផ្លូវការរបស់អ្នក
   * **Password:** លេខសម្ងាត់សុវត្ថិភាព (យ៉ាងហោចណាស់ ៨ តួអក្សរ រួមមានអក្សរធំ អក្សរតូច លេខ និងនិមិត្តសញ្ញា)
4. អាន និងយល់ព្រមលើ **Terms of Service** និង **Responsible Disclosure Policy**។
5. ចុចប៊ូតុង **Create Account**។
6. ពិនិត្យប្រអប់សំបុត្រ (Inbox) ក្នុងអ៊ីមែលរបស់អ្នកដើម្បីចុច link បញ្ជាក់ការចុះឈ្មោះ (Email Verification)។

***

## 🏢 ជំហានចុះឈ្មោះសម្រាប់ Company / Organization

1. ចូលទៅកាន់ទំព័រ [Account Type Selection](https://devsolve-frontend.vercel.app/account-type) ហើយជ្រើសរើស **"Company / Organization"** (ឬចូលផ្ទាល់ទៅកាន់ `/register/company`)។
2. បំពេញព័ត៌មានអំពីស្ថាប័នរបស់អ្នក៖
   * **Company Name:** ឈ្មោះក្រុមហ៊ុន ឬអង្គភាពផ្លូវការ
   * **Company Website:** គេហទំព័រផ្លូវការ (ឧ. `https://example.com`)
   * **Work Email:** អ៊ីមែលផ្លូវការរបស់ក្រុមហ៊ុន (សូមជៀសវាងការប្រើ free mail ដូចជា @gmail.com ឬ @yahoo.com)
   * **Industry / Sector:** វិស័យអាជីវកម្ម (Fintech, E-commerce, Healthcare, etc.)
   * **Representative Name & Role:** ឈ្មោះ និងតួនាទីរបស់អ្នកតំណាង (ឧ. Security Lead, CTO)
   * **Password:** លេខសម្ងាត់សុវត្ថិភាព
3. ចុចប៊ូតុង **Register Company**។
4. បញ្ជាក់អ៊ីមែលការងាររបស់អ្នកដើម្បីធ្វើឱ្យគណនីមានសកម្មភាព។
5. បន្ទាប់ពី Login សូមចូលទៅកាន់ Dashboard ដើម្បីស្នើសុំ **Company Verification** មុនពេល Publish កម្មវិធី Bounty ដំបូង។
