# Reports និង Organizations FAQ

<details>
<summary>ហេតុអ្វីមិនអាច Submit ទៅ Program?</summary>

បញ្ជាក់ថាអ្នក Sign in, Program Active, Target In Scope ហើយ Organization បាន Approve Researcher Access ប្រសិនបើត្រូវការ។

</details>

<details>
<summary>តើអាច Edit Report ក្រោយ Submit ទេ?</summary>

Report Review Screen បច្ចុប្បន្នព្រមានថាមិនអាច Edit ក្រោយ Submit។ ពិនិត្យ Draft ជាមុន ហើយប្រើ Private Collaboration សម្រាប់ Clarification។

</details>

<details>
<summary>Duplicate និង Needs More Information បង្ហាញនៅណា?</summary>

Backend រក្សា Detailed State។ Researcher List បច្ចុប្បន្ន Group Duplicate ជាមួយ Rejected និង Needs More Information ជាមួយ Triaging ខណៈ Report Detail អាចរក្សា Raw State។

</details>

<details>
<summary>Rewards Page បង្ហាញ Real Balance ឬ?</summary>

មិនទាន់ទេ។ ទំព័រដែលបានពិនិត្យប្រើ Demonstration Records។ កុំចាត់ទុក Totals ឬ Export ជា Payment Commitment។

</details>

<details>
<summary>ហេតុអ្វីមិនអាច Invite Team Member?</summary>

Invitee ត្រូវមាន DevSolve Account ក្រោម Email នោះជាមុន។ អ្នកត្រូវមាន Authority ហើយ Existing Membership ឬ Pending Invitation អាចរារាំង Invitation ថ្មី។

</details>

<details>
<summary>Researcher Access និង Team Membership ដូចគ្នាឬ?</summary>

ទេ។ Researcher Access អនុញ្ញាត External Researcher ឱ្យ Report។ Team Membership ផ្តល់ Internal Workspace Role និង Permissions។

</details>
