# Community FAQ

<a href="https://docs.devsolve.app/en/faq/community" class="button secondary">English</a>

<details>
<summary>Problem និង Vulnerability Report ខុសគ្នាដូចម្តេច?</summary>

Problem ជា Public Community Content ក្រោយអនុម័ត។ Vulnerability Report ជា Private Disclosure ទៅ Organization ក្រោម Program។ Sensitive Finding ត្រូវដាក់ជា Report។

</details>

<details>
<summary>ហេតុអ្វីមិនអាច Create Solution ពី New Post Screen?</summary>

Solution ត្រូវភ្ជាប់នឹង Problem។ បើក Problem ហើយជ្រើស Answer Action។

</details>

<details>
<summary>តើអាចឆ្លើយ Problem របស់ខ្លួនឯងទេ?</summary>

Solution Creation Screen បច្ចុប្បន្នមិនអនុញ្ញាត Problem Author ឆ្លើយ Problem របស់ខ្លួនទេ។

</details>

<details>
<summary>ហេតុអ្វី Post មិនទាន់ Public?</summary>

វាអាចជា Draft, Pending Approval ឬ Rejected។ បើក **My Community** ដើម្បីមើល State និង Actions។

</details>

<details>
<summary>Showcase គួរមានអ្វី?</summary>

Project, Architecture Explanation ឬ Technical Guide ដែលមាន Summary និង Build Steps ច្បាស់។ អ្នកអាចបន្ថែម Code, Screenshots, Diagrams, Technologies និង External Links។

</details>
