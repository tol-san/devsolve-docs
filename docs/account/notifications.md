# Notifications

<a href="/en/account/notifications" class="button secondary">English</a>

Notifications រួមបញ្ចូល Events ដែលគាំទ្រពាក់ព័ន្ធនឹង Account, Community, Access, Team, Program និង Report។

1. ជ្រើស Bell នៅ Public ឬ Dashboard Header។
2. ពិនិត្យ Unread Count និង Items ថ្មី។
3. បើក Item ដើម្បីទៅ Destination ដែលគាំទ្រ។
4. Mark Item as Read ឬ **Mark all as read**។
5. Refresh បើ Event ដែលរំពឹងមិនទាន់បង្ហាញ។

បើក **Dashboard → Notifications** សម្រាប់ Full Page។ Preference ត្រូវបានរក្សាតាម Controls ដែលមាន។ In-app និង Email Delivery អាស្រ័យលើ Event និង Backend Channel; មិនមែនគ្រប់ Event សុទ្ធតែផ្ញើទាំងពីរទេ។
