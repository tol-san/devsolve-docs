# Profile និង Settings

<a href="https://docs.devsolve.app/en/account/profile-and-settings" class="button secondary">🇬🇧 English</a>

Public Profile ជួយអ្នកប្រើផ្សេងយល់ពី Identity និង Contributions របស់អ្នក។

បើក **Dashboard → Profile** ហើយកែ៖

- Display/Personal Details និង Location
- Contact Details នៅពេលគាំទ្រ
- Biography ជាមួយ Markdown Preview
- GitHub, X, LinkedIn និង Website Links
- Avatar និង Cover Image

ប្រើ Profile Completion Indicator ជាការណែនាំ ពិនិត្យ Preview ហើយ Save។ Public Profile អាចបង្ហាញ Overview, Hacktivity, Community, Hall of Thanks, Badges, Severity Statistics និង Follow Relationships។

Settings បង្ហាញតែ Controls ដែល Frontend មាន។ Authentication គ្រប់គ្រងដោយ Identity Provider ដូច្នេះកុំសន្មតថា Settings អាចប្តូរ External Password ឬបង្ហាញ Active Sessions ទាំងអស់។
